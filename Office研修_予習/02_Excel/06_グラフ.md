# Excel-06：グラフ

---

## 1. グラフの作り方

1. グラフにしたい範囲を **見出しごと** 選択する
2. 挿入タブ →「おすすめグラフ」または各グラフのボタン
3. 「グラフのデザイン」「書式」タブで見た目を整える

```
選択範囲の例
     A        B        C
1            上期     下期       ← 見出し行 → 凡例になる
2  東京      1,200    1,500
3  大阪        800      950      ← 見出し列 → 項目軸（横軸）のラベルになる
4  名古屋      500      620
```

> ショートカット：範囲を選んで `Alt + F1` で同じシートに、`F11` で新しいグラフシートに作成されます。

---

## 2. グラフの種類と使い分け ★

**「何を伝えたいか」でグラフを選ぶ** のが鉄則です。

| 伝えたいこと | グラフ | 例 |
|--------------|--------|-----|
| 量の **大小を比較** | 縦棒グラフ | 支店別の売上 |
| 項目名が長い・項目が多い比較 | 横棒グラフ | 商品別売上ランキング |
| **時間による変化（推移）** | 折れ線グラフ | 月別売上の推移 |
| **全体に対する割合**（構成比）| 円グラフ / ドーナツグラフ | 商品別の売上構成比 |
| 割合の比較（複数の全体）| 100% 積み上げ棒グラフ | 年度ごとの構成比の変化 |
| 内訳と合計の両方 | 積み上げ縦棒グラフ | 月別売上（商品別の内訳つき）|
| 2 つの量の **相関** | 散布図 | 広告費と売上の関係 |
| 単位の違う 2 つの値 | 複合グラフ（棒 + 折れ線、第 2 軸）| 売上（棒）と利益率（折れ線）|
| 複数の指標のバランス | レーダーチャート | スキル評価 |

```
縦棒（比較）     折れ線（推移）     円（構成比）
  ▐█                    ╱●         ╭───╮
  ▐█ ▐█            ●──●            │ ╲ │
  ▐█ ▐█ ▐█      ●╱                 │  ╲│
 ─┴──┴──┴─     ──────────          ╰───╯
 東京 大阪 名古屋  4月 5月 6月 7月
```

### よくある間違い

| NG | 理由 | 代わりに |
|----|------|----------|
| 月別推移を円グラフで | 円グラフは「時間」を表現できない | 折れ線グラフ |
| 項目が 10 個以上の円グラフ | 細かすぎて読めない | 横棒グラフ、または上位 5 つ + 「その他」|
| 3D グラフ | 奥行きで大きさが歪んで見える | 2D グラフ |
| 縦軸が 0 から始まらない棒グラフ | 差が実際より大きく見える | 棒グラフの軸は 0 から |
| 円グラフの並び順がバラバラ | 比較しづらい | 大きい順に 12 時の位置から時計回り |

## 3. グラフの要素

```
            ┌───── グラフタイトル ─────┐
            │   支店別売上（2026年度上期） │
   (千円)   │                           │ ← 軸ラベル（単位）
   2,000 ┤ │                           │
         │ │  ▐█ 1,500                 │ ← データラベル
   1,000 ┤ │  ▐█      ▐█ 950           │
         │ │  ▐█      ▐█      ▐█ 620   │ ← 目盛線
       0 ┼─┴──┴───────┴───────┴─────── │ ← 縦（値）軸
            東京      大阪     名古屋     │ ← 横（項目）軸
                  ■上期  ■下期            │ ← 凡例
```

グラフを選択すると右上に表示される `＋`（グラフ要素）ボタンで、各要素の表示 / 非表示を切り替えられます。

| 要素 | ポイント |
|------|----------|
| グラフタイトル | 「グラフ タイトル」のまま放置しない。**何のグラフか** を書く |
| 軸ラベル | **単位**（円・千円・件・%）を必ず明記 |
| 凡例 | 系列が 1 つなら不要。データラベルで代用することも |
| データラベル | 正確な値を見せたいときに表示 |
| 目盛線 | 薄く、または削除してすっきりさせる |

## 4. グラフの編集

| やりたいこと | 操作 |
|--------------|------|
| グラフの種類を変更 | 「グラフのデザイン」→「グラフの種類の変更」|
| 行と列を入れ替える | 「グラフのデザイン」→「行/列の切り替え」（横軸と凡例が入れ替わる）|
| データ範囲を変更 | 「グラフのデザイン」→「データの選択」、または元の表の色付き枠をドラッグ |
| デザインを一括変更 | 「グラフのデザイン」→「グラフスタイル」「色の変更」|
| 特定の棒だけ色を変える | 棒を 1 回クリック（系列全体）→ もう 1 回クリック（その棒だけ）→ 塗りつぶし |
| 軸の最大値・最小値 | 軸をダブルクリック →「軸の書式設定」→「境界値」|
| 第 2 軸を使う | 「グラフの種類の変更」→「組み合わせ」→ 系列の「第 2 軸」にチェック |
| PowerPoint / Word に貼る | グラフを選択して `Ctrl + C` → 貼り付け先で `Ctrl + V` |

### 伝わるグラフにする工夫

- **強調したい 1 本だけ色を変え**、他はグレーにする
- タイトルに **結論** を書く：「支店別売上」より「東京支店が前年比 125% で全社を牽引」
- 不要な要素（目盛線・凡例・枠線）は削る

## 5. スパークライン

セルの中に小さなグラフを表示する機能です。表の中で傾向をひと目で見せたいときに便利です。

挿入タブ →「スパークライン」→「折れ線」/「縦棒」/「勝敗」

```
     A       B     C     D     E     F      G
1  支店     4月   5月   6月   7月   8月    推移
2  東京     120   135   128   150   162   ╱╲╱‾   ← スパークライン
3  大阪      90    85    88    80    75   ‾╲_╲
```

## やってみよう（15 分）

練習用ブックの「月別売上」シートを使います。

1. 支店別・月別の売上から **折れ線グラフ** を作り、タイトルを「支店別 月次売上推移」にする
2. 縦軸に「売上（千円）」の軸ラベルを付ける
3. 同じデータで「行/列の切り替え」を押し、何が変わるか確認する
4. 6 月の支店別売上だけを選択して **円グラフ** を作り、データラベルに「パーセンテージ」を表示する
5. 売上（縦棒）と前月比（折れ線・第 2 軸）の **複合グラフ** を作る
6. I 列に 4 月〜9 月（B〜G 列）のスパークラインを入れる
