# Excel-05：データ活用（並べ替え・フィルター・テーブル・ピボットテーブル）

---

## 1. データベース形式の表 ★

並べ替え・フィルター・ピボットテーブルを使うには、
表が **「データベース形式（リスト形式）」** になっている必要があります。

```
⭕ データベース形式
     A          B        C       D          E      F
1  日付        担当者   地域    商品        数量   金額      ← 1 行目は見出し（項目名）
2  2026/4/1    佐藤     東京    ノートPC      2   300000    ← 1 行 = 1 件のデータ
3  2026/4/1    鈴木     大阪    マウス       10    30000
4  2026/4/2    佐藤     東京    モニター      3   105000
```

| ルール | NG 例 |
|--------|-------|
| 1 行目に見出しを 1 行だけ置く | 見出しが 2 段になっている |
| 1 行に 1 件のデータ | 1 件のデータが 2 行にまたがる |
| 空白の行・列を入れない | 見やすくするために 1 行おきに空行 |
| セル結合をしない | 同じ担当者のセルを結合 |
| 同じ列には同じ種類のデータ | 金額列に「未定」「-」が混ざる |
| 表記を統一する | 「東京」「東京都」「ﾄｳｷｮｳ」が混在 |
| 表の周りは空ける | 表のすぐ下に合計行やメモ |

> **「人が見るための表」と「データとしての表」を分ける** のが Excel 上級者の考え方です。
> データはシンプルなデータベース形式で持ち、見せるための集計表はピボットテーブルや関数で別に作ります。

## 2. 並べ替え

### 簡単な並べ替え

並べ替えたい列のセルを 1 つ選択 → データタブ →「昇順（A→Z）」/「降順（Z→A）」

| | 数値 | 文字 | 日付 |
|-|------|------|------|
| 昇順 | 小 → 大 | あ → ん、A → Z | 古 → 新 |
| 降順 | 大 → 小 | ん → あ、Z → A | 新 → 古 |

> **列を選択して並べ替えてはいけません**。その列だけが並べ替えられて、
> 他の列とのデータの対応がバラバラになる危険があります。
> セルを 1 つだけ選択すれば、Excel が表全体を自動で認識します。

### 複数条件の並べ替え

データタブ →「並べ替え」で、優先順位を付けて複数の条件を指定できます。

```
最優先されるキー：地域   昇順
次に優先されるキー：金額 降順
→ 地域ごとにまとめた上で、各地域の中で金額の大きい順
```

「ユーザー設定リスト」を使うと、「東京 → 大阪 → 名古屋」のような独自の順番でも並べ替えられます。

> **元の順番に戻したくなる場合に備えて**、並べ替える前に「No.」列（連番）を作っておくと安心です。

## 3. フィルター ★

条件に合う行だけを表示する機能です。

表内のセルを選択 → データタブ →「フィルター」（`Ctrl + Shift + L`）

```
     A▼         B▼       C▼      D▼          E▼     F▼     ← 見出しに ▼ ボタンが付く
```

| フィルターの種類 | 例 |
|------------------|-----|
| 値で選ぶ | 地域で「東京」「大阪」にだけチェック |
| テキストフィルター | 「ノート」を含む / 「P」で始まる |
| 数値フィルター | 100,000 以上 / トップテン / 平均より上 |
| 日付フィルター | 今月 / 先週 / 指定の範囲 |
| 色フィルター | 条件付き書式などで色が付いたセルだけ |

- 複数の列に条件を設定すると **AND 条件**（すべて満たす行）になる
- 絞り込み中は行番号が青色になり、ステータスバーに「〇件中 △件が見つかりました」と表示される
- 解除：データタブ →「クリア」（条件だけ解除）、もう一度「フィルター」（▼ ごと解除）

### フィルター中の集計：SUBTOTAL / AGGREGATE

`SUM` はフィルターで非表示になった行も合計してしまいます。
表示されている行だけを集計したいときは `SUBTOTAL` を使います。

```
=SUBTOTAL(9, F2:F100)     ← 9 = 合計（表示されている行のみ）
=SUBTOTAL(3, A2:A100)     ← 3 = 個数（COUNTA）
```

> フィルター中に「オート SUM」ボタンを押すと、自動で SUBTOTAL が入力されます。

## 4. テーブル ★

データベース形式の表を **「テーブル」に変換** すると、便利な機能がまとめて使えるようになります。

表内のセルを選択 → 挿入タブ →「テーブル」（`Ctrl + T`）

### テーブルのメリット

| メリット | 説明 |
|----------|------|
| 自動拡張 | 表の下に行を追加すると、書式・数式・範囲が自動で広がる |
| 縞模様 | 1 行おきの色付け（行を追加・削除しても崩れない）|
| フィルター | 自動でフィルターボタンが付く |
| 見出しの固定 | スクロールすると列番号（A, B, C）の位置に見出しが表示される |
| 集計行 | 「テーブルデザイン」→「集計行」で合計・平均などを簡単に表示 |
| 構造化参照 | 数式で `=[@数量]*[@単価]` のように列名で参照できる |
| 範囲の自動更新 | ピボットテーブルやグラフの元データにすると、行を追加しても範囲が自動で広がる |

### 構造化参照

```
通常の参照：  =E2*F2
構造化参照：  =[@数量]*[@単価]        ← 「この行の数量 × この行の単価」と読める

テーブル全体の列：
=SUM(売上[金額])                      ← 売上テーブルの金額列の合計
```

テーブル名は「テーブルデザイン」タブの左端で変更できます（既定は「テーブル1」）。

> 「元に戻したい」場合は「テーブルデザイン」→「範囲に変換」で通常の表に戻せます。

## 5. ピボットテーブル ★★

大量のデータを、**ドラッグ操作だけで様々な角度から集計** できる機能です。
関数を 1 つも書かずに、クロス集計表が数秒で作れます。

### 作り方

1. 表内のセルを選択 → 挿入タブ →「ピボットテーブル」→「OK」（新規ワークシートに作成）
2. 右側の「ピボットテーブルのフィールド」で、項目を 4 つのエリアにドラッグする

```
┌─ ピボットテーブルのフィールド ──────────┐
│ ☐ 日付                                │
│ ☑ 担当者                              │
│ ☑ 地域                                │
│ ☐ 商品                                │
│ ☐ 数量                                │
│ ☑ 金額                                │
├──────────────────┬───────────────────┤
│ ▼ フィルター       │ ‖ 列               │
│                  │   地域              │
├──────────────────┼───────────────────┤
│ ≡ 行              │ Σ 値               │
│   担当者          │   合計 / 金額       │
└──────────────────┴───────────────────┘
```

結果：

```
合計 / 金額    列ラベル ▼
行ラベル ▼     大阪       東京       名古屋      総計
佐藤                    1,250,000    150,000   1,400,000
鈴木          420,000                            420,000
高橋                       85,000    360,000     445,000
総計          420,000   1,335,000    510,000   2,265,000
```

### 4 つのエリアの役割

| エリア | 役割 | 例 |
|--------|------|-----|
| 行 | 縦に並べる項目 | 担当者 |
| 列 | 横に並べる項目 | 地域 |
| 値 | 集計する数値 | 金額（合計）|
| フィルター | 全体の絞り込み | 商品（ノートPC のみ）|

### よく使う操作

| やりたいこと | 操作 |
|--------------|------|
| 合計を平均・個数に変える | 値エリアの項目をクリック →「値フィールドの設定」|
| 桁区切りを付ける | 「値フィールドの設定」→「表示形式」|
| 構成比（%）を出す | 「値フィールドの設定」→「計算の種類」→「総計に対する比率」|
| 日付を月単位で集計 | 日付を行エリアに入れると自動でグループ化される（右クリック →「グループ化」で調整）|
| 詳細データを見る | 集計値のセルをダブルクリック → 元データが新しいシートに表示される |
| 元データの変更を反映 | ピボットテーブル内で右クリック →「更新」★ |
| スライサーで絞り込み | 「ピボットテーブル分析」→「スライサーの挿入」|

> **ピボットテーブルは元データを変更しても自動では更新されません。** 必ず「更新」を押しましょう。
> 元データに行を追加する場合は、元データを **テーブル** にしておくと範囲も自動で広がります。

## 6. その他の便利機能

| 機能 | 用途 | 場所 |
|------|------|------|
| 重複の削除 | 同じデータの行を削除 | データタブ →「重複の削除」|
| 区切り位置 | 1 つのセルの「東京都,千代田区」をカンマで 2 列に分割 | データタブ →「区切り位置」|
| 小計 | 並べ替えた後、グループごとの小計行を自動挿入 | データタブ →「小計」|
| グループ化（アウトライン）| 行や列を折りたためるようにする | データタブ →「グループ化」|
| ゴールシーク | 「利益を 100 万円にするには売上がいくら必要か」を逆算 | データタブ →「What-If 分析」|
| CSV の取り込み | 文字化けせずに CSV を読み込む | データタブ →「テキストまたは CSV から」|

> **CSV を Excel でダブルクリックして開くと、文字化けしたり「001」が「1」になったりすることがあります。**
> 「データ」→「テキストまたは CSV から」で取り込むと、文字コードや列のデータ型を指定できます。

## やってみよう（20 分）

練習用ブックの「売上データ」シートを使います。

1. 「地域の昇順 → 金額の降順」で並べ替える
2. フィルターで「東京」かつ「金額が 100,000 以上」の行だけを表示し、件数を確認する
3. フィルター中に SUM と SUBTOTAL(9, …) の結果を比べる
4. 表をテーブルに変換し、最終行の下にデータを 1 件追加して、書式が自動で広がることを確認する
5. ピボットテーブルで「行：担当者」「列：地域」「値：金額の合計」の表を作る
6. 値を「総計に対する比率」に変えて、担当者ごとの構成比を表示する
7. 日付を行エリアに入れて、月別の売上集計を作る
