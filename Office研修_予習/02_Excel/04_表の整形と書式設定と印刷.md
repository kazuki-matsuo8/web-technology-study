# Excel-04：表の整形・書式設定・印刷

---

## 1. 見やすい表の基本ルール

```
❌ 見づらい表                         ⭕ 見やすい表
┏━━━━┳━━━━━━┳━━━━━┓             ┌──────┬────────┬────────┐
┃東京 ┃ 1500000┃  12.5┃             │ 地域 │ 売上(円) │ 構成比 │ ← 見出しに単位
┣━━━━╋━━━━━━╋━━━━━┫             ├──────┼────────┼────────┤
┃大阪 ┃  980000┃8.16666┃             │ 東京 │ 1,500,000 │  12.5% │ ← 桁区切り・%
┗━━━━┻━━━━━━┻━━━━━┛             │ 大阪 │   980,000 │   8.2% │ ← 小数をそろえる
 太い罫線・色が多すぎる               └──────┴────────┴────────┘
```

| ルール | 理由 |
|--------|------|
| 数値は **右揃え**、文字は **左揃え** | 桁がそろって比較しやすい |
| 数値に **桁区切り（,）** を付ける | 1500000 は一目で読めない |
| 見出しに **単位** を書く | セルごとに「円」を付けると計算に使えなくなる |
| 小数点以下の桁数を **そろえる** | 12.5 と 8.16666 が混在すると読みづらい |
| 罫線は **細く・控えめに** | 太い罫線は情報ではなくノイズになる |
| 色は **2〜3 色まで** | 見出し行の背景と強調色くらいに抑える |
| **セル結合は最小限に** | 並べ替え・フィルター・コピーの邪魔になる |

> **セル結合の代わりに「選択範囲内で中央」**：
> 複数セルの中央に文字を置きたいときは、`Ctrl + 1` →「配置」→ 横位置「選択範囲内で中央」を使うと、
> 見た目は結合と同じで、データとしては結合しない状態にできます。

## 2. 表示形式 ★

**表示形式は「見た目」だけを変えるもので、セルの値そのものは変わりません。**
`Ctrl + 1` →「表示形式」タブで設定します。

| 表示形式 | 値 | 表示 | ショートカット / ボタン |
|----------|-----|------|------------------------|
| 標準 | 1234.5 | 1234.5 | |
| 数値（桁区切り）| 1234567 | 1,234,567 | ホーム →「桁区切りスタイル（,）」|
| 通貨 | 1234567 | ¥1,234,567 | ホーム →「通貨表示形式」|
| パーセント | 0.125 | 13%（小数桁数で 12.5%）| ホーム →「%」|
| 日付 | 46307 | 2026/10/12 | |
| 文字列 | 001 | 001 | |

### 小数点以下の表示桁数

ホームタブの「小数点以下の表示桁数を増やす / 減らす」ボタンで調整できます。

### ユーザー定義の表示形式

`Ctrl + 1` →「表示形式」→「ユーザー定義」で、独自の形式を作れます。

| 書式記号 | 値 | 表示 | 説明 |
|----------|-----|------|------|
| `#,##0` | 1234567 | 1,234,567 | 桁区切り |
| `#,##0"円"` | 1500 | 1,500円 | 単位を付ける（値は数値のまま計算できる）|
| `#,##0,` | 1234567 | 1,235 | 千円単位で表示 |
| `0000` | 12 | 0012 | ゼロ埋め |
| `yyyy/mm/dd` | 46307 | 2026/10/12 | |
| `m月d日(aaa)` | 46307 | 10月12日(月) | 曜日付き |
| `aaaa` | 46307 | 月曜日 | 曜日だけ |
| `[h]:mm` | 1.5 | 36:00 | 24 時間を超える時間（勤務時間の合計など）|

> `"円"` を表示形式で付けると、**見た目は「1,500円」でも値は数値の 1500** のままです。
> セルに直接「1500円」と入力すると文字列になり、計算できなくなります。

## 3. 罫線・配置・セルのスタイル

### 罫線

ホームタブ →「罫線」▼

| 罫線 | 使いどころ |
|------|-----------|
| 格子 | 表全体に一括で罫線を引く |
| 外枠太罫線 | 表の外周だけ太く |
| 下二重罫線 | 合計行の上（会計の慣習）|

細かく設定する場合は `Ctrl + 1` →「罫線」タブ。

### 配置

| 機能 | 使いどころ |
|------|-----------|
| 折り返して全体を表示 | 長い文章をセル幅で折り返す |
| 縮小して全体を表示 | セル幅に合わせて文字を小さくする |
| 縦書き / 文字の方向 | 見出しを縦書きにする |
| インデント | 階層のある項目（大分類・小分類）を字下げで表現 |

### セルのスタイル・テーブルスタイル

ホームタブ →「セルのスタイル」や「テーブルとして書式設定」を使うと、
統一感のあるデザインを一瞬で適用できます。

## 4. 条件付き書式 ★

**条件に合うセルだけ自動で色を付ける** 機能です。
「目標未達のセルを赤く」「期限切れのタスクをグレーに」など、実務で多用します。

ホームタブ →「条件付き書式」

| 種類 | 例 |
|------|-----|
| セルの強調表示ルール | 100,000 より大きい値を赤字に / 重複する値に色を付ける |
| 上位 / 下位ルール | 上位 10 項目 / 平均より上 |
| データバー | セル内に棒グラフを表示 |
| カラースケール | 値の大小を色の濃淡で表示（ヒートマップ）|
| アイコンセット | ↑ → ↓ や信号の色のアイコン |

### 数式を使った条件付き書式（行全体に色を付ける）

「ステータスが『完了』の行全体をグレーにする」場合：

1. 表のデータ範囲（例：`A2:E100`）を選択
2. 条件付き書式 →「新しいルール」→「数式を使用して、書式設定するセルを決定」
3. 数式に `=$E2="完了"` と入力（**列だけ固定** するのがポイント）
4. 「書式」でグレーの塗りつぶしを設定

```
=$E2="完了"
 └─ E 列は固定（どの列のセルでも E 列のステータスを見る）
    行は相対（各行が自分の行の E 列を見る）
```

> ここでも複合参照（Excel-02）の理解が必要です。

設定したルールの確認・削除は「条件付き書式」→「ルールの管理」から行います。

## 5. 入力規則（ドロップダウンリスト）

入力できる値を制限し、**入力ミスや表記ゆれを防ぐ** 機能です。

データタブ →「データの入力規則」

| 設定 | 例 |
|------|-----|
| リスト | 「未着手,対応中,完了」から選択させる（ドロップダウン）|
| 整数 | 1〜100 の整数のみ |
| 日付 | 2026/4/1 以降のみ |
| 文字列（長さ指定）| 10 文字以内 |
| 日本語入力 | セルを選ぶと自動で IME をオン / オフ |

```
ステータス列にリストを設定すると…
┌──────────┐
│ 対応中  ▼ │
├──────────┤
│ 未着手     │
│ 対応中     │ ← 選ぶだけなので「対応中」「対応 中」「たいおう中」などの表記ゆれが起きない
│ 完了       │
└──────────┘
```

> 課題管理表・テスト仕様書などで、ステータス列にはほぼ必ずリストが設定されています。

## 6. 印刷 ★

Excel の印刷は **「画面で見えている通りに印刷されない」** ので、必ずプレビューを確認します。

### 印刷前に確認すること

| 確認項目 | 設定場所 |
|----------|----------|
| 印刷プレビュー | `Ctrl + P` |
| 用紙サイズ・向き | ページレイアウトタブ /「印刷」画面 |
| 1 ページに収める | 「印刷」画面 →「拡大縮小なし」→「シートを 1 ページに印刷」/「すべての列を 1 ページに印刷」|
| 印刷範囲 | 範囲を選択 → ページレイアウトタブ →「印刷範囲」→「印刷範囲の設定」|
| 見出し行を毎ページ印刷 | ページレイアウトタブ →「印刷タイトル」→「タイトル行」に `$1:$1` |
| ヘッダー / フッター | 「ページ設定」→「ヘッダー/フッター」でページ番号・ファイル名など |
| 改ページ位置 | 表示タブ →「改ページプレビュー」で青い線をドラッグ |

### 改ページプレビュー

表示タブ →「改ページプレビュー」にすると、
印刷される範囲が白、印刷されない範囲がグレーで表示され、
**青い点線（自動改ページ）をドラッグして調整** できます。

> 「すべての列を 1 ページに印刷」は、横に長い表で列が 2 ページ目にはみ出すのを防ぐ定番設定です。
> 「シートを 1 ページに印刷」は、行が多いと文字が極端に小さくなるので注意。

## 7. ブックの保護と共有

| 機能 | 用途 | 場所 |
|------|------|------|
| シートの保護 | 数式のセルを書き換えられないようにする | 校閲タブ →「シートの保護」|
| セルのロック解除 | 保護しても入力できるセルを作る | `Ctrl + 1` →「保護」→「ロック」のチェックを外す |
| ブックの保護 | シートの追加・削除・名前変更を禁止 | 校閲タブ →「ブックの保護」|
| パスワード | ファイルを開くのにパスワードを要求 | ファイル →「情報」→「ブックの保護」|
| コメント / メモ | セルに補足を付ける | 右クリック →「新しいコメント」/「新しいメモ」|

### 入力フォームの作り方（よくある流れ）

1. 入力してほしいセルだけ選択 → `Ctrl + 1` →「保護」→「ロック」を外す
2. 校閲タブ →「シートの保護」
3. → 入力欄以外（見出しや数式）は変更できなくなる
