
## 1. IF 関数（条件分岐）★★★

条件によって表示する値を変えます。

```
=IF(条件, 真の場合, 偽の場合)

=IF(F2>=100000, "大口", "通常")
    └─ 金額が 10 万以上なら「大口」、そうでなければ「通常」
```

- 文字列は `"`（ダブルクォーテーション）で囲む
- 何も表示したくないときは `""`（空文字）

```
=IF(B2="", "", B2*C2)    ← B2 が空なら空白、そうでなければ計算
```

### 条件を組み合わせる：AND / OR / NOT

| 関数 | 意味 | 例 |
|------|------|-----|
| `AND(条件1, 条件2, …)` | すべて満たす | `=IF(AND(C2="東京", F2>=100000), "重点", "")` |
| `OR(条件1, 条件2, …)` | どれか 1 つでも満たす | `=IF(OR(C2="東京", C2="大阪"), "大都市", "その他")` |
| `NOT(条件)` | 条件を反転 | `=IF(NOT(C2="東京"), "東京以外", "東京")` |

### 3 つ以上に分ける：IF のネスト / IFS

点数で評価を付ける例（80 以上 A、60 以上 B、それ未満 C）：

```
IF のネスト（入れ子）：
=IF(B2>=80, "A", IF(B2>=60, "B", "C"))

IFS（Excel 2019 以降）：
=IFS(B2>=80, "A", B2>=60, "B", TRUE, "C")
```

> **条件を書く順番が大事** です。`B2>=60` を先に書くと、90 点の人も「B」になってしまいます。
> 厳しい条件（大きい値）から順に判定しましょう。
> `IFS` の最後の `TRUE` は「それ以外すべて」の意味です。

## 2. COUNTIF / SUMIF / AVERAGEIF（条件付き集計）★★★

「条件に合うものだけ」数える・合計する関数です。実務で非常によく使います。

### COUNTIF：条件に合うセルの数

```
=COUNTIF(範囲, 条件)

=COUNTIF(C2:C100, "東京")       → 地域が「東京」の件数
=COUNTIF(F2:F100, ">=100000")   → 金額が 10 万以上の件数
=COUNTIF(B2:B100, H2)           → 担当者が H2 のセルの値と一致する件数
```

### SUMIF：条件に合う行の合計

```
=SUMIF(条件範囲, 条件, 合計範囲)

=SUMIF(C2:C100, "東京", F2:F100)
       └─条件範囲  └条件  └─合計範囲
→ 地域が「東京」の行の金額を合計
```

### 複数条件：COUNTIFS / SUMIFS / AVERAGEIFS

```
=COUNTIFS(条件範囲1, 条件1, 条件範囲2, 条件2, …)
=SUMIFS(合計範囲, 条件範囲1, 条件1, 条件範囲2, 条件2, …)

=SUMIFS(F2:F100, C2:C100, "東京", D2:D100, "ノートPC")
→ 地域が「東京」かつ商品が「ノートPC」の金額合計
```

> **注意**：`SUMIF` は合計範囲が **最後**、`SUMIFS` は合計範囲が **最初** です。
> 混乱しやすいので、迷ったら条件が 1 つでも `SUMIFS` を使うと統一できます。

### 条件の書き方

| 条件 | 書き方 |
|------|--------|
| 「東京」と等しい | `"東京"` |
| 「東京」以外 | `"<>東京"` |
| 10 万以上 | `">=100000"` |
| セル H1 の値以上 | `">="&H1`（演算子とセル参照を `&` でつなぐ）|
| 「ノート」で始まる | `"ノート*"`（`*` は任意の文字列）|
| 空白 | `""` |
| 空白でない | `"<>"` |
| 日付 2026/4/10 以降 | `">=2026/4/10"` または `">="&DATE(2026,4,10)` |

### 集計表を作るときのコツ

```
     H          I                                    J
1  地域       件数                                 金額合計
2  東京       =COUNTIF($C$2:$C$100, H2)            =SUMIF($C$2:$C$100, H2, $F$2:$F$100)
3  大阪       （上の式をコピー）
4  名古屋
```

- 条件を `"東京"` と直接書かず、**セル（H2）を参照** すると下にコピーするだけで全地域分が完成する
- データ範囲は **絶対参照** にしておかないと、コピー時にずれる

## 3. VLOOKUP / XLOOKUP（表引き）★★★

**コード（ID）から、別の表にある名前や価格を引っ張ってくる** 関数です。
Excel 研修のハイライトと言っても過言ではありません。

### 例：商品コードから商品名と単価を表示する

```
【商品マスタ】(Sheet「商品マスタ」)       【注文表】
     A        B           C               A         B         C       D
1  コード    商品名       単価          1  コード    商品名    単価    数量
2  P001     ノートPC    150000          2  P003      ?         ?       2
3  P002     マウス        3000          3  P001      ?         ?       1
4  P003     モニター     35000
5  P004     キーボード    8000
```

### VLOOKUP

```
=VLOOKUP(検索値, 範囲, 列番号, 検索方法)

=VLOOKUP(A2, 商品マスタ!$A$2:$C$5, 2, FALSE)
         │    │                    │  └─ FALSE：完全一致（実務ではほぼ必ず FALSE）
         │    │                    └──── 範囲の左から 2 列目（商品名）を返す
         │    └────────────────────────── 検索する表（絶対参照にする）
         └─────────────────────────────── 探す値（P003）
→ 「モニター」
```

単価なら列番号を 3 にします：`=VLOOKUP(A2, 商品マスタ!$A$2:$C$5, 3, FALSE)` → 35000

#### VLOOKUP の注意点

| 注意点 | 説明 |
|--------|------|
| 第 4 引数は `FALSE` | 省略すると近似一致（`TRUE`）になり、**間違った値が返ってもエラーにならない** |
| 検索値は範囲の **一番左の列** | 範囲の左側にある列の値は取ってこられない |
| 範囲は絶対参照 | コピー時にずれないように `$` を付ける |
| 列を挿入すると壊れる | 列番号を数字で指定しているため、マスタに列を足すとずれる |
| 見つからないと `#N/A` | `IFERROR` で対処（後述）|

### XLOOKUP（Microsoft 365 / Excel 2021 以降）

VLOOKUP の弱点を解消した新しい関数です。研修環境で使えるなら、こちらがおすすめです。

```
=XLOOKUP(検索値, 検索範囲, 戻り範囲, [見つからない場合])

=XLOOKUP(A2, 商品マスタ!$A$2:$A$5, 商品マスタ!$B$2:$B$5, "該当なし")
         │    └─ コードの列          └─ 商品名の列           └─ 見つからないときの表示
→ 「モニター」
```

| | VLOOKUP | XLOOKUP |
|-|---------|---------|
| 既定の検索方法 | 近似一致（`FALSE` 指定が必要）| **完全一致** |
| 戻り値の列の指定 | 列番号（数字）| 範囲（列を挿入しても壊れない）|
| 検索列より左の値 | 取れない | **取れる** |
| 見つからない場合 | `#N/A`（IFERROR が必要）| 第 4 引数で指定できる |
| 使えるバージョン | すべて | 365 / 2021 以降 |

> 現場では古いファイルや古い Excel もまだ多いので、**VLOOKUP も読めるようにしておく** 必要があります。

### INDEX + MATCH（参考）

XLOOKUP がない環境で、VLOOKUP の弱点を補うための定番の組み合わせです。

```
=INDEX(商品マスタ!$B$2:$B$5, MATCH(A2, 商品マスタ!$A$2:$A$5, 0))
       └─ 取り出したい列       └─ A2 が何番目にあるかを調べる（0 は完全一致）
```

## 4. IFERROR（エラー時の表示）

```
=IFERROR(値, エラーの場合の値)

=IFERROR(VLOOKUP(A2, 商品マスタ!$A$2:$C$5, 2, FALSE), "コード未登録")
=IFERROR(B2/C2, 0)                ← 0 除算エラーを 0 と表示
=IFERROR(VLOOKUP(…), "")          ← エラーなら空白
```

> **注意**：IFERROR は「どんなエラーも隠す」ので、数式自体の間違いにも気づけなくなります。
> 完成して動作確認が済んでから付けるのがおすすめです。

## 5. 文字列関数

| 関数 | 機能 | 例 | 結果 |
|------|------|-----|------|
| `LEFT(文字列, 文字数)` | 左から取り出す | `=LEFT("P001-A", 4)` | P001 |
| `RIGHT(文字列, 文字数)` | 右から取り出す | `=RIGHT("P001-A", 1)` | A |
| `MID(文字列, 開始位置, 文字数)` | 途中から取り出す | `=MID("2026-10-12", 6, 2)` | 10 |
| `LEN(文字列)` | 文字数 | `=LEN("Excel")` | 5 |
| `FIND(検索文字列, 対象)` | 位置を探す | `=FIND("-", "P001-A")` | 5 |
| `TRIM(文字列)` | 余分なスペースを削除 | `=TRIM(" 山田  太郎 ")` | 山田 太郎 |
| `SUBSTITUTE(文字列, 旧, 新)` | 置き換え | `=SUBSTITUTE("090-1234", "-", "")` | 0901234 |
| `UPPER` / `LOWER` | 大文字 / 小文字に | `=UPPER("abc")` | ABC |
| `ASC` / `JIS` | 半角 / 全角に | `=ASC("ＡＢＣ")` | ABC |
| `TEXT(値, 表示形式)` | 数値を書式付き文字列に | `=TEXT(A1, "yyyy年m月d日")` | 2026年10月12日 |
| `CONCAT` / `&` | 連結 | `=B2&"様"` | 佐藤様 |

### 組み合わせの例：メールアドレスからユーザー名を取り出す

```
=LEFT(A2, FIND("@", A2)-1)

A2 = "matsuo@example.com"
FIND("@", A2) → 7
LEFT(A2, 6)   → "matsuo"
```

## 6. 日付関数

| 関数 | 機能 | 例 | 結果 |
|------|------|-----|------|
| `TODAY()` | 今日 | | 2026/10/12 |
| `DATE(年, 月, 日)` | 日付を作る | `=DATE(2026,10,12)` | 2026/10/12 |
| `YEAR` / `MONTH` / `DAY` | 年 / 月 / 日を取り出す | `=MONTH(A2)` | 10 |
| `WEEKDAY(日付)` | 曜日番号（日曜=1）| `=WEEKDAY("2026/10/12")` | 2（月曜）|
| `EOMONTH(日付, 月数)` | 月末日 | `=EOMONTH(A2, 0)` | 2026/10/31 |
| `EDATE(日付, 月数)` | ○か月後の同日 | `=EDATE(A2, 3)` | 2027/1/12 |
| `NETWORKDAYS(開始, 終了, [祝日])` | 土日祝を除く営業日数 | | |
| `WORKDAY(開始, 日数, [祝日])` | ○営業日後の日付 | `=WORKDAY(A2, 5)` | 2026/10/19 |
| `DATEDIF(開始, 終了, "Y")` | 期間（年数）| 年齢・勤続年数の計算 | |

> `DATEDIF` は関数の候補に表示されない「隠し関数」ですが、手入力すれば使えます。
> `"Y"`（満年数）、`"M"`（満月数）、`"D"`（日数）を指定します。

## 7. 新しい関数（Microsoft 365 / 2021 以降）

1 つの数式の結果が複数のセルに広がる（**スピル**する）関数です。

| 関数 | 機能 | 例 |
|------|------|-----|
| `UNIQUE(範囲)` | 重複を除いた一覧 | `=UNIQUE(C2:C100)` → 地域の一覧 |
| `SORT(範囲, 列, 順序)` | 並べ替えた結果 | `=SORT(A2:F100, 6, -1)` → 金額の降順 |
| `FILTER(範囲, 条件)` | 条件に合う行だけ抽出 | `=FILTER(A2:F100, C2:C100="東京")` |

```
H2 に =UNIQUE(C2:C100) と入力するだけで…
     H
2  東京       ← 数式は H2 にだけ入っている
3  大阪       ← 結果が自動で下に広がる（スピル）
4  名古屋
```

これと COUNTIF を組み合わせると、地域別集計表が一瞬で作れます。

## 8. 関数選びの早見表

| やりたいこと | 関数 |
|--------------|------|
| 合計・平均・最大・最小 | SUM / AVERAGE / MAX / MIN |
| 個数を数える | COUNT（数値）/ COUNTA（空白以外）|
| 条件で表示を変える | IF / IFS |
| 条件に合うものを数える | COUNTIF / COUNTIFS |
| 条件に合うものを合計する | SUMIF / SUMIFS |
| コードから名前・価格を引く | VLOOKUP / XLOOKUP |
| エラーを隠す | IFERROR |
| 四捨五入・切り捨て | ROUND / ROUNDDOWN |
| 順位を付ける | RANK.EQ |
| 文字の一部を取り出す | LEFT / RIGHT / MID |
| 日付の計算 | TODAY / DATE / EOMONTH / DATEDIF |
