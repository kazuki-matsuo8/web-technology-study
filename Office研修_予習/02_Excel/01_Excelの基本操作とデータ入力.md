# Excel-01：Excel の基本操作とデータ入力

---

## 1. Excel の用語

```
        A列     B列     C列
      ┌──────┬──────┬──────┐
 1行  │ A1   │ B1   │ C1   │   ← 1 つのマスを「セル」と呼ぶ
      ├──────┼──────┼──────┤      セルの位置は「列番号＋行番号」で表す（セル番地）
 2行  │ A2   │ B2   │ C2   │
      ├──────┼──────┼──────┤
 3行  │ A3   │ B3   │ C3   │   ← A1:C3 のような「範囲」で複数セルを指定する
      └──────┴──────┴──────┘
      [Sheet1] [Sheet2] [+]     ← シート（ワークシート）
```

| 用語 | 意味 |
|------|------|
| ブック | Excel ファイル 1 つ（`.xlsx`）|
| シート | ブックの中の 1 枚の表。下部のタブで切り替える |
| セル | 1 つのマス |
| セル番地（参照）| `A1`、`C5` のような位置の表し方 |
| 範囲 | `A1:C3`（A1 から C3 までの四角形の範囲）|
| アクティブセル | 現在選択されている（太枠の）セル |
| 名前ボックス | 左上の、アクティブセルの番地が表示される欄 |
| 数式バー | セルの中身（数式）が表示される欄 |
| フィルハンドル | 選択範囲の右下の小さな■。ドラッグでコピー・連続データ入力 |

## 2. データの種類

Excel は入力された値を自動で判別します。

| 種類 | 例 | 既定の配置 |
|------|-----|-----------|
| 数値 | `100`、`3.14`、`-5` | **右揃え** |
| 日付・時刻 | `2026/10/12`、`9:30` | **右揃え**（内部的には数値）|
| 文字列 | `東京`、`ABC` | **左揃え** |
| 数式 | `=A1+B1` | 計算結果による |

> 数値なのに左に寄っている → **文字列として入力されている** 可能性があります。
> このままでは計算に使えないので要注意です（セルの左上に緑の三角マークが出ます）。

### よくある自動変換のトラブル

| 入力 | 勝手に変わる結果 | 対策 |
|------|-----------------|------|
| `1-2` | `1月2日` | 先頭に `'`（シングルクォート）を付けて `'1-2` |
| `001` | `1` | `'001` と入力、または表示形式を「文字列」に |
| `(1)` | `-1` | `'(1)` と入力 |
| `1/2` | `1月2日` | `'1/2` と入力 |
| `1234567890123456789`（16 桁以上）| `1.23457E+18`、16 桁目以降が 0 になる | 表示形式を「文字列」にしてから入力 |

`'` を付けると「文字列として扱う」という意味になり、`'` 自体はセルに表示されません。

### 日付は「シリアル値」

Excel の日付は内部的には **1900/1/1 を 1 とした通し番号** です。

```
2026/10/12 → 46307
```

だから日付同士の引き算で日数が計算できます（`=B1-A1` → 経過日数）。
表示形式を「標準」にすると、日付が数字に化けて見えるのはこのためです。

## 3. 移動と選択のショートカット ★

Excel はショートカットを使うかどうかで作業速度が何倍も変わります。

### 移動

| ショートカット | 移動先 |
|----------------|--------|
| `Ctrl + 矢印` | データの端（空白セルの手前）までジャンプ |
| `Ctrl + Home` | A1 セル |
| `Ctrl + End` | データが入っている最後のセル |
| `Ctrl + Page Down / Up` | 次 / 前のシート |
| `Enter` / `Shift + Enter` | 下 / 上のセル |
| `Tab` / `Shift + Tab` | 右 / 左のセル |
| `Ctrl + G` または `F5` | 指定したセル番地へジャンプ |

### 選択

| ショートカット | 選択範囲 |
|----------------|----------|
| `Shift + 矢印` | 1 セルずつ範囲を広げる |
| `Ctrl + Shift + 矢印` | データの端まで一気に選択 ★ |
| `Ctrl + A` | 表全体（もう一度押すとシート全体）|
| `Ctrl + Space` | 列全体 |
| `Shift + Space` | 行全体（日本語入力オンだと効かないので半角モードで）|
| `Ctrl + クリック` | 離れたセルを複数選択 |

> **1 万行のデータを選択するとき**、マウスでドラッグすると時間がかかります。
> 先頭セルを選んで `Ctrl + Shift + ↓` なら一瞬です。

## 4. 入力・編集のショートカット ★

| ショートカット | 操作 |
|----------------|------|
| `F2` | セルを編集モードにする（ダブルクリックと同じ）|
| `Alt + Enter` | セル内で改行 |
| `Ctrl + Enter` | 選択した全セルに同じ値を入力 |
| `Ctrl + D` | 上のセルをコピー（下方向へコピー）|
| `Ctrl + R` | 左のセルをコピー（右方向へコピー）|
| `Ctrl + ;` | 今日の日付を入力 |
| `Ctrl + :` | 現在の時刻を入力 |
| `Ctrl + 1` | 「セルの書式設定」を開く ★ |
| `Ctrl + -` | セル / 行 / 列の削除 |
| `Ctrl + Shift + ;`（`Ctrl + +`）| セル / 行 / 列の挿入 |
| `Delete` | セルの中身を消す（書式は残る）|
| `Esc` | 入力をキャンセル |
| `Ctrl + Z` | 元に戻す |

## 5. オートフィル ★

フィルハンドル（選択範囲右下の ■）をドラッグすると、データを自動で入力できます。

| 元のデータ | ドラッグした結果 |
|------------|------------------|
| `1` | `1, 1, 1, …`（コピー）|
| `1` を `Ctrl` を押しながらドラッグ | `1, 2, 3, …`（連番）|
| `1`, `2`（2 つ選択してドラッグ）| `1, 2, 3, 4, …` |
| `1`, `3`（2 つ選択）| `1, 3, 5, 7, …`（差分で増える）|
| `月` | `月, 火, 水, 木, …` |
| `1月` | `1月, 2月, 3月, …` |
| `2026/10/12` | `2026/10/13, 10/14, …`（1 日ずつ）|
| `第1四半期` | `第2四半期, 第3四半期, …` |
| `=A1*2` | 数式がずれながらコピーされる（Excel-02 で解説）|

- ドラッグ後に表示される「オートフィルオプション」で「連続データ」「セルのコピー」「書式なしコピー」などを切り替えられます
- **フィルハンドルをダブルクリック** すると、隣の列のデータがある最終行まで一気にコピーされます（大量データで便利）

### フラッシュフィル

規則性のあるデータを、例を 1 つ入力するだけで自動入力してくれる機能です。

```
   A列（氏名）     B列（姓）
   松尾 和樹       松尾       ← 1 つ目だけ手入力
   山田 太郎       山田       ← Ctrl + E で残りが自動入力される
   佐藤 花子       佐藤
```

2 つ目のセルを選択して `Ctrl + E`（またはデータタブ →「フラッシュフィル」）。

## 6. 行・列・シートの操作

| やりたいこと | 操作 |
|--------------|------|
| 列幅を自動調整 | 列番号の境界線をダブルクリック |
| 複数列の幅をそろえる | 複数列を選択して境界線をドラッグ |
| 行・列の挿入 | 行番号 / 列番号を右クリック →「挿入」|
| 行・列を非表示 | 右クリック →「非表示」（再表示は前後の列を選んで「再表示」）|
| シートの追加 | シートタブ右の `⊕` |
| シート名の変更 | シートタブをダブルクリック |
| シートのコピー | `Ctrl` を押しながらシートタブをドラッグ |
| シートの色 | シートタブを右クリック →「シート見出しの色」|

### ウィンドウ枠の固定 ★

縦に長い表をスクロールしても、**見出し行がずっと表示される** ようにする機能です。

表示タブ →「ウィンドウ枠の固定」

| 選択するセル | 固定される範囲 |
|--------------|----------------|
| A2 | 1 行目 |
| B1 | A 列 |
| B2 | 1 行目と A 列 |

選択したセルの **上の行と左の列** が固定される、と覚えましょう。

## やってみよう（10 分）

1. A1 に `1` を入力し、`Ctrl` を押しながらフィルハンドルを A100 までドラッグして連番を作る
2. A1 を選択した状態で `Ctrl + ↓`、`Ctrl + ↑` を押してジャンプを体験する
3. A1 を選択して `Ctrl + Shift + ↓` で A1:A100 を一気に選択し、ステータスバーの「合計」を確認する（5050 になれば OK）
4. B1 に `月` と入力してオートフィルで曜日を作る
5. C1 に `001` と入力して `1` になることを確認し、`'001` で入力し直す
6. 1 行目を固定（A2 を選択 → ウィンドウ枠の固定）してスクロールしてみる
