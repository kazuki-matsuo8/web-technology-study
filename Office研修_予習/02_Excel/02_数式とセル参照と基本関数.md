# Excel-02：数式・セル参照・基本関数

---

## 1. 数式の基本

数式は必ず **`=`（イコール）から始めます**。

```
=10+20        → 30
=A1+B1        → A1 と B1 の値を足す
=A1*1.1       → A1 の値に 1.1 を掛ける（税込価格など）
=SUM(A1:A10)  → A1〜A10 の合計（関数）
```

### 演算子

| 演算子 | 意味 | 例 | 結果 |
|--------|------|-----|------|
| `+` | 足し算 | `=5+3` | 8 |
| `-` | 引き算 | `=5-3` | 2 |
| `*` | 掛け算 | `=5*3` | 15 |
| `/` | 割り算 | `=6/3` | 2 |
| `^` | べき乗 | `=2^3` | 8 |
| `&` | 文字列の連結 | `="山田"&"様"` | 山田様 |

### 比較演算子（IF 関数などで使う）

| 演算子 | 意味 |
|--------|------|
| `=` | 等しい |
| `<>` | 等しくない |
| `>` / `<` | より大きい / より小さい |
| `>=` / `<=` | 以上 / 以下 |

### 計算の優先順位

算数と同じく、`*` `/` が `+` `-` より先に計算されます。

```
=10+20*2     → 50（20*2 が先）
=(10+20)*2   → 60（括弧が先）
```

> **数式には「値」ではなく「セル番地」を書くのが鉄則** です。
> `=1000*1.1` ではなく `=B2*C2` と書けば、元の値を変えたときに結果も自動で変わります。

## 2. 相対参照と絶対参照 ★★★

**Excel 研修で最も重要で、最もつまずきやすいポイント** です。必ず手を動かして理解しましょう。

### 相対参照（`A1`）

数式をコピーすると、**参照先も一緒にずれます**。

```
     A        B       C
1  単価     数量     金額
2  100      3       =A2*B2   ← この数式を下にコピーすると…
3  200      5       =A3*B3   ← 自動で 3 行目を参照するように変わる
4  150      2       =A4*B4
```

これが便利なので、Excel では普通は相対参照を使います。

### 絶対参照（`$A$1`）

数式をコピーしても、**参照先が固定されて動きません**。

```
     A        B          C
1  消費税率   10%
2
3  商品       価格       税込価格
4  りんご     100       =B4*(1+$B$1)   ← 税率のセルは B1 に固定したい
5  みかん     200       =B5*(1+$B$1)
6  ぶどう     500       =B6*(1+$B$1)
```

もし `$` を付けずに `=B4*(1+B1)` としてコピーすると…

```
5  みかん     200       =B5*(1+B2)   ← B2 は空なので税率 0 として計算されてしまう！
```

### 複合参照（`$A1` / `A$1`）

行だけ、または列だけを固定します。

| 書き方 | 列 | 行 | 意味 |
|--------|----|----|------|
| `A1` | 動く | 動く | 相対参照 |
| `$A$1` | 固定 | 固定 | 絶対参照 |
| `$A1` | 固定 | 動く | 列だけ固定 |
| `A$1` | 動く | 固定 | 行だけ固定 |

`$` は「**直後のものを固定する**」記号です。`$A` なら A 列を固定、`$1` なら 1 行目を固定。

### F4 キーで切り替え

数式の入力中にセル番地にカーソルを置いて `F4` を押すと、順番に切り替わります。

```
A1 → $A$1 → A$1 → $A1 → A1 → …
```

### 複合参照の定番例：九九の表

```
      A    B    C    D    …
1          1    2    3    …   ← 1 行目に掛ける数
2     1    =$A2*B$1
3     2
4     3
…
```

B2 に `=$A2*B$1` と入力し、右と下にコピーすると九九の表が完成します。

- `$A2`：A 列は固定（左端の数を常に参照）、行は動く
- `B$1`：1 行目は固定（上端の数を常に参照）、列は動く

> **考え方**：「この数式をコピーしたとき、どこは動いてほしくないか？」を考えて `$` を付けます。

## 3. 基本の関数

### 関数の書き方

```
=関数名(引数1, 引数2, …)

=SUM(A1:A10)
 │   └───── 引数（関数に渡すデータ）
 └── 関数名
```

関数名の最初の数文字を入力すると候補が表示されるので、`Tab` キーで確定できます。
また「関数の挿入」ボタン（数式バーの左の `fx`）から、ダイアログで引数を指定することもできます。

### 集計の基本 6 関数 ★

| 関数 | 機能 | 例 |
|------|------|-----|
| `SUM` | 合計 | `=SUM(B2:B10)` |
| `AVERAGE` | 平均 | `=AVERAGE(B2:B10)` |
| `MAX` | 最大値 | `=MAX(B2:B10)` |
| `MIN` | 最小値 | `=MIN(B2:B10)` |
| `COUNT` | **数値** が入っているセルの数 | `=COUNT(B2:B10)` |
| `COUNTA` | **空白でない** セルの数（文字も数える）| `=COUNTA(A2:A10)` |

> `COUNT` と `COUNTA` の違いはよく出題されます。
> 「出席者の人数（名前の数）」を数えるなら `COUNTA`、「点数が入っている人数」なら `COUNT`。

### オート SUM

ホームタブまたは数式タブの「オート SUM（Σ）」ボタンで、合計範囲を自動で推測して入力してくれます。
ショートカットは `Alt + Shift + =`（日本語キーボードでは `Alt + Shift + -`、「ほ」のキー）。

▼ をクリックすると、平均・数値の個数・最大値・最小値も選べます。

### 端数処理

| 関数 | 機能 | `=関数(1234.567, 1)` | `=関数(1234.567, -2)` |
|------|------|------|------|
| `ROUND` | 四捨五入 | 1234.6 | 1200 |
| `ROUNDUP` | 切り上げ | 1234.6 | 1300 |
| `ROUNDDOWN` | 切り捨て | 1234.5 | 1200 |
| `INT` | 小数点以下を切り捨て（整数化）| `=INT(1234.567)` → 1234 | |

第 2 引数（桁数）の意味：

```
 1 2 3 4 . 5 6 7
      │   │ │
     -2   0 1    ← 桁数。0 なら整数、1 なら小数第 1 位まで、-2 なら百の位まで
```

> **表示形式で小数点以下を非表示にしても、値自体は丸められていません。**
> 合計が合わない原因になるため、金額計算では `ROUND` などで実際に丸めましょう。

### その他よく使う基本関数

| 関数 | 機能 | 例 | 結果 |
|------|------|-----|------|
| `TODAY` | 今日の日付 | `=TODAY()` | 2026/10/12 |
| `NOW` | 現在の日時 | `=NOW()` | 2026/10/12 10:30 |
| `RANK.EQ` | 順位 | `=RANK.EQ(B2,$B$2:$B$10)` | 大きい順の順位 |
| `ABS` | 絶対値 | `=ABS(-5)` | 5 |
| `MOD` | 割り算の余り | `=MOD(10,3)` | 1 |

> `RANK.EQ` の範囲は絶対参照（`$B$2:$B$10`）にしないと、コピーしたときに範囲がずれます。
> 絶対参照が必要になる典型例です。

## 4. エラー値の意味 ★

| エラー | 意味 | よくある原因 |
|--------|------|-------------|
| `#DIV/0!` | 0 で割った | 割る数のセルが空白または 0 |
| `#N/A` | 値が見つからない | VLOOKUP / XLOOKUP で検索値が存在しない |
| `#NAME?` | 関数名などが認識できない | 関数名のスペルミス、文字列を `"` で囲み忘れ |
| `#REF!` | 参照先が無効 | 参照していたセルや行・列を削除した |
| `#VALUE!` | 値の種類が不適切 | 文字列に対して計算しようとした |
| `#NUM!` | 数値が不適切 | 計算結果が大きすぎる、不正な引数 |
| `#SPILL!` | 結果を表示する範囲が埋まっている | スピル（複数セルに結果が広がる数式）の先にデータがある |
| `#####` | エラーではなく **列幅が足りない** | 列幅を広げれば表示される |

### エラーを調べる方法

- エラーのセルを選択すると表示される `⚠` アイコンから、原因の説明が見られます
- 数式タブ →「参照元のトレース」で、どのセルを参照しているか矢印で表示できます
- `Ctrl + Shift + @`（または数式タブ →「数式の表示」）で、シート上の全セルの数式を表示できます
