# PowerPoint-03：図解・グラフ・アニメーション

---

## 1. 図解の基本パターン

文章を図解にすると、関係性がひと目で伝わります。
よく使うパターンは次の 6 つです。

| パターン | 表すもの | 例 |
|----------|----------|-----|
| 流れ（フロー）| 手順・時系列・プロセス | 要件定義 → 設計 → 開発 → テスト |
| 比較（表・左右）| 2 つ以上のものの違い | 現行システム vs 新システム |
| 階層（ツリー）| 上下関係・分類 | 組織図、機能一覧 |
| 循環（サイクル）| 繰り返すプロセス | PDCA サイクル |
| 包含（ベン図）| 重なり・共通部分 | 3 つのスキルの重なり |
| マトリクス（4 象限）| 2 軸での分類 | 重要度 × 緊急度 |

```
流れ                          比較
┌───┐  ┌───┐  ┌───┐          ┌─────────┬─────────┐
│要件│→│設計│→│開発│          │ Before  │ After   │
└───┘  └───┘  └───┘          │ 手作業   │ 自動化   │
                              │ 60 分    │ 5 分    │
                              └─────────┴─────────┘

循環                          マトリクス
    ┌──Plan──┐                     重要
    ↑        ↓                ┌────────┬────────┐
  Act       Do                │ 計画的に │ すぐやる │
    ↑        ↓           緊急でない├────────┼────────┤緊急
    └─Check──┘                │ やらない │ 任せる   │
                              └────────┴────────┘
                                     重要でない
```

## 2. SmartArt ★

挿入タブ →「SmartArt」で、図解を簡単に作れます。

| 分類 | 用途 |
|------|------|
| リスト | 箇条書きを図形にする |
| 手順 | 流れ・ステップ |
| 循環 | サイクル |
| 階層構造 | 組織図・ツリー |
| 集合関係 | ベン図など |
| マトリックス | 4 象限 |
| ピラミッド | 階層・比率 |

### 箇条書きから SmartArt に変換

既に入力した箇条書きを選択 → ホームタブ →「SmartArt に変換」で、一瞬で図解にできます。

```
・要件定義                   ┌──────┐  ┌──────┐  ┌──────┐
・設計          → 変換 →     │要件定義│→│ 設計 │→│ 開発 │
・開発                       └──────┘  └──────┘  └──────┘
```

### SmartArt の編集

| 操作 | 方法 |
|------|------|
| 項目を追加 | 左側のテキストウィンドウで `Enter` |
| レベルを下げる | テキストウィンドウで `Tab` |
| デザインを変える | 「SmartArt のデザイン」→「レイアウト」/「色の変更」/「スタイル」|
| 自由に編集したい | 右クリック →「図形に変換」→ グループ解除（通常の図形になる）|

## 3. 表

挿入タブ →「表」

| ポイント | 説明 |
|----------|------|
| 罫線は最小限 | 横線だけ、または縞模様で十分 |
| 見出し行を目立たせる | 背景色＋白文字＋太字 |
| 数値は右揃え | 桁をそろえる |
| 強調したいセルだけ色を変える | 「ここを見てほしい」を明確に |
| 行数は少なく | 細かいデータは配布資料や Excel で。スライドには要点だけ |

## 4. グラフ

### PowerPoint でグラフを作る方法

| 方法 | 特徴 |
|------|------|
| 挿入タブ →「グラフ」| PowerPoint 内で Excel のシートが開き、データを入力して作成 |
| Excel のグラフをコピーして貼り付け | Excel で作ったグラフをそのまま使う |

### 貼り付けのオプション

| オプション | 特徴 |
|------------|------|
| 貼り付け先のテーマを使用しブックを埋め込む | PowerPoint のデザインに合わせる。データも一緒に保存 |
| 元の書式を保持しブックを埋め込む | Excel の見た目のまま |
| 貼り付け先テーマを使用しデータをリンク | 元の Excel を更新すると反映される（ファイルの場所を移動するとリンクが切れる）|
| 図 | 画像として貼る（編集不可だが、見た目が崩れない）|

### スライドのグラフのポイント

Excel-06 の内容に加えて、スライドでは特に次の点を意識します。

- **タイトルに結論を書く**：「売上推移」ではなく「売上は 3 か月連続で増加」
- **見せたい部分だけ色を付ける**：他はグレーにして、強調したい棒だけ色を付ける
- **文字を大きく**：Excel の既定のままだと、軸の数字が小さすぎて読めない
- **補助線・矢印・吹き出しで注目点を示す**

```
⭕ 伝わるグラフ
 売上は 9 月に過去最高を記録          ← 結論のタイトル
   │                    ▐█ ← 過去最高！（吹き出し）
   │          ▐▒ ▐▒ ▐▒ ▐█
   │ ▐▒ ▐▒ ▐▒ ▐▒ ▐▒ ▐▒ ▐█      ▐▒：グレー
   └──────────────────────     ▐█：強調色
    4月 5月 6月 7月 8月 9月
```

## 5. 画面切り替えとアニメーション

### 画面切り替え（スライドが切り替わるときの効果）

画面切り替えタブで設定します。

- ビジネスでは「**なし**」か「**フェード**」程度の控えめなもので十分
- 「すべてに適用」で全スライドに同じ効果を設定する（スライドごとに変えない）

### アニメーション（スライド内の要素の動き）

アニメーションタブで設定します。

| 種類 | 効果 | 使いどころ |
|------|------|-----------|
| 開始 | 要素が現れる | 説明に合わせて項目を 1 つずつ表示 |
| 強調 | 要素が目立つ | 重要な数字を点滅・色変化 |
| 終了 | 要素が消える | 前の説明を消して次へ |
| アニメーションの軌跡 | 要素が移動する | （ビジネスではあまり使わない）|

### アニメーションのルール ★

| ⭕ 良い使い方 | ❌ 悪い使い方 |
|--------------|--------------|
| 話す順番に合わせて項目を表示（聴衆が先読みしない）| すべての文字が回転しながら飛んでくる |
| 手順の流れを矢印の順に表示 | スライドごとに違う派手な効果 |
| 「フェード」「ワイプ」などシンプルな効果 | 意味のない動きで時間がかかる |

> **アニメーションは「目的」があるときだけ使う** のが鉄則です。
> 「話の順番どおりに見せたい」「ここに注目させたい」以外の目的では使わないようにしましょう。

### アニメーションの設定方法

1. 要素を選択 → アニメーションタブ → 効果を選ぶ
2. 「アニメーションウィンドウ」を開くと、順番や開始タイミングを調整できる
3. 開始のタイミング：

| タイミング | 意味 |
|-----------|------|
| クリック時 | クリックしたら動く（基本）|
| 直前の動作と同時 | 前のアニメーションと同時に動く |
| 直前の動作の後 | 前のアニメーションが終わったら自動で動く |

4. 箇条書きの場合：「効果のオプション」→「段落別」にすると 1 行ずつ表示される

> 「アニメーションのコピー/貼り付け」（ハケのアイコン）で、同じ効果を他の要素にコピーできます。

## やってみよう（15 分）

1. 「要件定義・設計・開発・テスト・リリース」の箇条書きを入力し、「SmartArt に変換」で手順の図にする
2. PDCA サイクルを SmartArt の「循環」で作る
3. 挿入タブ →「グラフ」で集合縦棒グラフを作り、1 本だけ色を変えてタイトルを結論にする
4. 箇条書き 3 項目に「フェード」を設定し、1 行ずつ表示されるようにする
