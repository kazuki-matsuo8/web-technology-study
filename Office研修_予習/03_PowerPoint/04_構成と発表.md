# PowerPoint-04：プレゼンテーションの構成と発表

研修の最後に「成果発表」や「グループ発表」があることは多いです。
スライドの作り方だけでなく、**構成の考え方と発表のコツ** も押さえておきましょう。

---

## 1. いきなりスライドを作らない ★

```
❌ PowerPoint を開いて 1 枚目から作り始める
   → 途中で話がつながらなくなり、作り直し

⭕ ① 目的と聞き手を決める
   ② 伝えたいこと（結論）を 1 文で書く
   ③ 構成（ストーリー）を紙やアウトラインで考える
   ④ スライドを作る
   ⑤ リハーサル
```

### ① 目的と聞き手

| 確認すること | 例 |
|--------------|-----|
| 誰に？ | 人事部の方・先輩社員・同期 |
| 何のために？ | 研修の成果を報告する / 提案を承認してもらう |
| 聞き手は何を知っている？ | 研修内容は知っているが、自分の学びは知らない |
| 聞き手にどうしてほしい？ | 成長を理解してもらう / 提案に賛成してもらう |
| 時間は？ | 5 分 → スライド 5〜7 枚程度（1 枚 1 分前後が目安）|

### ② 結論を 1 文で

「このプレゼンで一番伝えたいことは？」を 1 文で書けないなら、まだスライドを作る段階ではありません。

```
例：「Excel 研修で学んだ関数を使えば、課題管理の手作業を 9 割削減できる」
```

## 2. 構成の型 ★★

### PREP 法（短い報告・意見を述べるとき）

| 順番 | 内容 | 例 |
|------|------|-----|
| **P**oint | 結論 | Excel 研修で最も役立ったのは VLOOKUP です |
| **R**eason | 理由 | 手作業の転記をなくせるからです |
| **E**xample | 具体例 | 演習では 50 件の転記が 5 分から数秒になりました |
| **P**oint | 結論（再度）| 配属後も VLOOKUP を活用して業務を効率化します |

### SDS 法（全体像を伝えるとき）

| 順番 | 内容 |
|------|------|
| **S**ummary | 概要（これから何を話すか）|
| **D**etails | 詳細 |
| **S**ummary | まとめ |

### 課題解決型（提案するとき）

```
現状 → 課題 → 原因 → 解決策 → 効果 → 今後の計画
```

### 研修成果発表の構成例（5 分・7 枚）

| No. | スライド | 内容 |
|-----|----------|------|
| 1 | 表紙 | タイトル・日付・氏名 |
| 2 | 結論 | 「〇〇を学び、△△ができるようになった」|
| 3 | 研修の概要 | 期間・内容（簡潔に）|
| 4 | 学び ① | 具体例・ビフォーアフター |
| 5 | 学び ② | 具体例・ビフォーアフター |
| 6 | 今後の活かし方 | 配属後にどう使うか |
| 7 | まとめ | 結論の再確認・お礼 |

> **結論を最初に言う** のがビジネスプレゼンの基本です。
> 「最後まで聞かないと何が言いたいか分からない」構成は避けましょう。

## 3. 発表のコツ

### 話し方

| ポイント | 説明 |
|----------|------|
| スライドを読み上げない | スライドに書いてあることは聴衆も読める。**補足・具体例・理由を話す** |
| 聴衆を見る | 画面ではなく聴衆の方を向く。会場全体に視線を配る |
| 間（ま）を取る | 重要なことを言う前後に 1〜2 秒の間 |
| 数字は具体的に | 「たくさん」より「50 件」 |
| 結論から話す | 各スライドでも、まずタイトル（結論）を言ってから説明 |
| 声の大きさ・速さ | 普段よりゆっくり、はっきり。1 分間に 300 文字程度が目安 |
| 「えー」「あのー」を減らす | 言葉に詰まったら黙って間を取る方が印象が良い |

### スライドの指し示し方

- 「こちらのグラフの、右端の棒をご覧ください」のように **言葉で場所を示す**
- レーザーポインター（`Ctrl + L`）は小さく動かす。ぐるぐる回さない

### リハーサル ★

| 方法 | 内容 |
|------|------|
| 声に出して通す | 頭の中だけでなく、実際に声に出して時間を計る |
| リハーサル機能 | スライドショータブ →「リハーサル」で各スライドの所要時間を記録 |
| 録画 | スライドショータブ →「録画」で自分の話し方を確認 |
| 発表者コーチ（Microsoft 365）| 話す速さ・つなぎ言葉・スライドの読み上げをフィードバックしてくれる |
| 人に見てもらう | 同期同士で発表し合い、フィードバックをもらう |

> 制限時間を超えるのは、ビジネスではマイナス評価になります。
> **制限時間の 9 割程度** で終わるように調整しましょう。

## 4. 質疑応答

| ポイント | 説明 |
|----------|------|
| 質問を最後まで聞く | 途中で遮らない |
| 質問を繰り返す / 確認する | 「〇〇についてのご質問ですね」→ 他の聴衆にも質問内容が伝わる |
| 結論から答える | 「はい / いいえ」「〇〇です」→ 理由 |
| 分からないときは正直に | 「確認して後ほど回答いたします」。その場しのぎで適当に答えない |
| 予備スライド | 想定質問への回答スライドを **非表示スライド** として末尾に用意しておく |
| お礼を言う | 「ご質問ありがとうございます」|
