# PowerPoint-02：伝わるスライドのデザイン原則

PowerPoint 研修で一番大事なのは、操作よりも **「伝わるスライドとは何か」** という考え方です。
センスではなく **ルール** で作れるので、この章のルールを覚えておきましょう。

---

## 1. 1 スライド 1 メッセージ ★★★

**1 枚のスライドで伝えることは 1 つだけ** にします。

```
❌ 悪い例
┌──────────────────────────────────┐
│ 研修について                        │
│ ・研修は10月から開始し、Word・Excel・   │
│   PowerPointの3つを学びます。Excelは  │
│   特に重要で、関数やピボットテーブルを │
│   扱います。また、ビジネスマナー研修も │
│   あり、名刺交換や電話応対を学びます。 │
│   最後に成果発表会があります。        │
└──────────────────────────────────┘
 何が言いたいのか分からない／文章を読まされる

⭕ 良い例
┌──────────────────────────────────┐
│ 研修は「3 ステップ」で進みます         │ ← タイトルがメッセージ
│                                  │
│  ① Office    →  ② マナー  →  ③ 発表会  │
│  10月          11月         12月      │
└──────────────────────────────────┘
 ひと目で全体像が分かる
```

### タイトルは「メッセージ」にする

| ❌ ただのラベル | ⭕ メッセージ（結論）|
|----------------|---------------------|
| 売上推移 | 売上は 3 か月連続で増加 |
| アンケート結果 | 受講者の 85% が「満足」と回答 |
| 課題 | 最大の課題は入力ミスによる手戻り |
| 現行システムの問題点 | 現行システムは月 20 時間の手作業を発生させている |

> **タイトルだけを順に読めば、プレゼン全体のストーリーが分かる** のが理想です。

## 2. 文字を減らす ★

スライドは「読ませるもの」ではなく「**見せるもの**」です。

| ルール | 目安 |
|--------|------|
| 文章ではなく **箇条書き** にする | 「〜です。〜ます。」を使わず体言止め |
| 箇条書きは少なく | 1 スライド 3〜5 項目まで |
| 1 項目は短く | 1〜2 行以内 |
| 説明は口頭で | 詳しい説明はスライドではなくノートに書いて話す |

```
❌ 文章
・Excel の VLOOKUP 関数を使うことによって、
  手作業で行っていた転記作業が自動化され、
  作業時間を大幅に削減することができました。

⭕ 箇条書き（体言止め）
・VLOOKUP で転記作業を自動化
・作業時間：60 分 → 5 分（92% 削減）
```

> 数字を入れると説得力が一気に上がります。「大幅に削減」より「92% 削減」。

## 3. フォント

| 項目 | ルール |
|------|--------|
| 種類 | **ゴシック体**（メイリオ / 游ゴシック / BIZ UDP ゴシック / Meiryo UI）|
| 種類の数 | 1 つのプレゼンで **1〜2 種類** まで |
| サイズ | タイトル 28〜40pt / 本文 **18pt 以上**（大きな会場ならさらに大きく）|
| 強調 | 太字か色のどちらか。**下線・斜体・影・ワードアートは避ける** |

- 明朝体は細く、プロジェクターで投影すると見えにくい
- 日本語の斜体は形が崩れて読みにくい
- フォントは **スライドマスター** で統一する

> **ユニバーサルデザインフォント（UD フォント）**：BIZ UDP ゴシックなどは、
> 誰にとっても読みやすいように設計されており、ビジネス資料に向いています。

## 4. 色 ★

| ルール | 説明 |
|--------|------|
| 使う色は **3 色まで** | ベースカラー・メインカラー・アクセントカラー |
| 配分の目安 | ベース 70%：メイン 25%：アクセント 5% |
| 強調色は 1 つ | 赤やオレンジなど、目立たせたい所だけに使う |
| 背景は白か薄い色 | 文字とのコントラストをはっきりさせる |
| **色だけ** で情報を区別しない | 色の見え方は人によって異なる。形・ラベル・線種も併用 |

```
ベースカラー（70%）  ：白・薄いグレー   → 背景
メインカラー（25%）  ：紺               → タイトル、図形
アクセントカラー（5%）：オレンジ         → 一番伝えたい数字だけ
文字色              ：黒に近い濃いグレー
```

> 色の選択に迷ったら、会社のロゴやコーポレートカラーをメインカラーにすると統一感が出ます。

## 5. デザインの 4 原則 ★★

ロビン・ウィリアムズ『ノンデザイナーズ・デザインブック』で紹介されている、
デザインの基本原則です。これだけでスライドは見違えます。

### ① 近接（Proximity）

**関連するものは近づけ、関係ないものは離す。**

```
❌                          ⭕
Word                        Word
ビジネス文書                ビジネス文書
Excel                       
関数                        Excel
PowerPoint                  関数
デザイン                    
                            PowerPoint
                            デザイン
```

見出しとその説明をグループとして近づけ、グループ間に余白を入れます。

### ② 整列（Alignment）

**要素の位置を、見えない線でそろえる。**

```
❌ バラバラ                ⭕ 左端がそろっている
  ■ タイトル               ■ タイトル
     本文テキスト            本文テキスト
 図形                      図形
    注釈                    注釈
```

- 中央揃えを多用するとそろっている線が見えにくくなるので、**左揃えが基本**
- 配置機能（PowerPoint-01）を使う

### ③ 反復（Repetition）

**同じ種類の要素には、同じデザインを繰り返す。**

- すべてのスライドでタイトルの位置・フォント・色を同じにする
- 同じ意味の図形は同じ色・形にする（例：「課題」は常にオレンジの四角）

→ スライドマスターと「既定の図形に設定」で実現できる

### ④ 対比（Contrast）

**違うものは、はっきり違うように見せる。**

- タイトルと本文のサイズ差を大きくする（中途半端な差は「ミス」に見える）
- 強調したい数字だけ大きく・色を変える
- 中途半端に似ている色やサイズは避ける

## 6. 余白とレイアウト

| ルール | 説明 |
|--------|------|
| 余白を恐れない | スライドの端ギリギリまで詰めない。上下左右に余白を |
| 視線の流れ | 人は **左上 → 右下**（Z 型）、または上 → 下（F 型）に見る |
| 情報の順番 | 時系列・手順は **左 → 右** または **上 → 下** |
| 重要なものは左上 | 最初に目に入る位置に結論を置く |

```
Z 型の視線
┌──────────────────┐
│ ① ──────────→ ② │
│         ╱        │
│       ╱          │
│ ③ ──────────→ ④ │
└──────────────────┘
```

## 7. 画像・アイコンの使い方

| ルール | 説明 |
|--------|------|
| 意味のある画像だけ | 「なんとなく寂しいから」で画像を入れない |
| 縦横比を崩さない | 拡大縮小は `Shift` を押しながら四隅をドラッグ |
| 画質 | 粗い・ぼやけた画像は使わない |
| 著作権 | ネットで拾った画像を勝手に使わない。PowerPoint の「ストック画像」「アイコン」（挿入タブ）は利用可能 |
| トリミング | 不要な部分は「図の形式」→「トリミング」で切る |

---

## 8. チェックリスト

スライドを作り終えたら、次の項目を確認しましょう。

- [ ] 1 スライド 1 メッセージになっているか
- [ ] タイトルを順に読めばストーリーが分かるか
- [ ] 文章ではなく箇条書き（体言止め）になっているか
- [ ] 本文は 18pt 以上か
- [ ] フォントは 1〜2 種類、色は 3 色以内か
- [ ] 図形や文字の位置はそろっているか（配置機能を使ったか）
- [ ] 同じ種類の要素は同じデザインか
- [ ] 画像の縦横比が崩れていないか
- [ ] 誤字脱字はないか（校閲 →「スペルチェック」）
- [ ] スライド番号が入っているか（質疑応答で「〇ページの…」と言える）
- [ ] 一番後ろの席から読めるか（スライド一覧表示で縮小して確認すると分かりやすい）
