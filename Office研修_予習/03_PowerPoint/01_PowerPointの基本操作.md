# PowerPoint-01：PowerPoint の基本操作

---

## 1. 画面構成

```
┌──────────────────────────────────────────────────┐
│ ファイル ホーム 挿入 描画 デザイン 画面切り替え アニメーション スライドショー 校閲 表示 │
├──────────────────────────────────────────────────┤
│ リボン                                            │
├────────┬─────────────────────────────────────────┤
│ 1 ▭    │                                         │
│ 2 ▭    │        スライドペイン（編集領域）           │
│ 3 ▭    │                                         │
│        │                                         │
│ サムネイル├─────────────────────────────────────────┤
│        │ ノートペイン（発表者用のメモ）              │
├────────┴─────────────────────────────────────────┤
│ スライド 1/10   ノート  標準 一覧 閲覧 スライドショー  ズーム │
└──────────────────────────────────────────────────┘
```

| 名称 | 役割 |
|------|------|
| サムネイルペイン | スライドの一覧。ドラッグで順番を入れ替え |
| スライドペイン | 編集中のスライド |
| ノートペイン | 発表時に話す内容のメモ。発表者ツールで自分だけに見える |
| プレースホルダー | 「タイトルを入力」などと書かれた点線の枠。ここに入力する |

### 表示モード

| モード | 用途 |
|--------|------|
| 標準 | 通常の編集 |
| スライド一覧 | 全体の流れを確認・順番の入れ替え |
| ノート | ノートを印刷イメージで編集 |
| 閲覧表示 | ウィンドウ内でスライドショーを確認 |
| スライドショー | 発表本番（全画面）|

## 2. スライドの操作

| 操作 | 方法 |
|------|------|
| 新しいスライド | `Ctrl + M`、またはホームタブ →「新しいスライド」|
| スライドの複製 | `Ctrl + D`（サムネイルで選択時）|
| スライドの削除 | サムネイルで選択して `Delete` |
| 順番の入れ替え | サムネイルをドラッグ |
| レイアウト変更 | ホームタブ →「レイアウト」|
| 非表示スライド | サムネイルを右クリック →「非表示スライドに設定」（発表時に飛ばす。質疑応答用の予備スライドに便利）|
| セクション | サムネイルを右クリック →「セクションの追加」（章ごとにまとめて折りたためる）|

### 主なレイアウト

| レイアウト | 用途 |
|------------|------|
| タイトルスライド | 表紙 |
| タイトルとコンテンツ | 最も基本。タイトル＋本文（箇条書き・表・グラフ）|
| セクション見出し | 章の区切り |
| 2 つのコンテンツ | 左右比較（Before / After など）|
| タイトルのみ | 図解を自由に配置したいとき |
| 白紙 | 全面画像など |

> **テキストボックスを自分で追加するより、レイアウトのプレースホルダーを使う** のが基本です。
> プレースホルダーに入力した文字はアウトライン表示や目次に反映され、
> デザイン（テーマ）を変えたときにも位置やフォントが自動で整います。

## 3. 文字の入力と箇条書き

| 操作 | キー |
|------|------|
| 箇条書きのレベルを下げる | `Tab` |
| 箇条書きのレベルを上げる | `Shift + Tab` |
| 箇条書きのまま改行（行頭記号なし）| `Shift + Enter` |
| 次のプレースホルダーへ移動 | `Ctrl + Enter` |

### アウトライン表示

表示タブ →「アウトライン表示」にすると、全スライドの文字だけが一覧表示されます。
**構成を考える段階では、ここで文字だけを先に打ち込む** と効率的です。

```
1 ▭ Office 研修 成果報告
      2027年度 内定者 松尾 和樹
2 ▭ 研修の目的
      ・配属後に必要な資料作成スキルを身につける
      ・ビジネス文書の基本ルールを理解する
3 ▭ 学んだこと
      ・Word：ビジネス文書の型
      ・Excel：関数と集計
```

アウトラインでの `Enter` → `Shift + Tab` で新しいスライドを作れます。

## 4. 図形・画像の操作 ★

| 操作 | 方法 |
|------|------|
| 正方形・正円・水平線 | `Shift` を押しながらドラッグ |
| 縦横比を保って拡大縮小 | `Shift` を押しながら四隅のハンドルをドラッグ |
| 中心から拡大縮小 | `Ctrl` を押しながらドラッグ |
| コピー | `Ctrl` を押しながらドラッグ（`Ctrl + Shift` で水平・垂直方向にコピー）|
| 複製 | `Ctrl + D`（連続で押すと等間隔に複製される）|
| 少しずつ移動 | 矢印キー（`Ctrl + 矢印` でさらに細かく）|
| グループ化 / 解除 | `Ctrl + G` / `Ctrl + Shift + G` |
| 書式のコピー / 貼り付け | `Ctrl + Shift + C` / `Ctrl + Shift + V` |
| 前面 / 背面へ | 右クリック →「最前面へ移動」/「最背面へ移動」|
| 図形の種類を変える | 図形の書式 →「図形の編集」→「図形の変更」|
| 選択ウィンドウ | ホーム →「配置」→「オブジェクトの選択と表示」（重なった図形を選びやすくなる）|

### 配置（整列）★

図形をそろえるのはドラッグではなく、**配置機能** を使います。

図形を複数選択 → 図形の書式タブ →「配置」

| 機能 | 効果 |
|------|------|
| 左揃え / 左右中央揃え / 右揃え | 横方向の位置をそろえる |
| 上揃え / 上下中央揃え / 下揃え | 縦方向の位置をそろえる |
| 左右に整列 | 横方向の **間隔を均等に** する |
| 上下に整列 | 縦方向の **間隔を均等に** する |
| スライドに合わせて配置 | スライドの中央などにそろえる |

> 表示タブ →「ガイド」「グリッド線」を表示すると、配置の目安になります。
> ドラッグ中に表示される赤い点線（スマートガイド）もそろえる助けになります。

### 既定の図形に設定

好みの色・枠線に設定した図形を右クリック →「既定の図形に設定」にすると、
以降に挿入する図形がすべてその書式になります。毎回色を変える手間が省けます。

## 5. スライドマスター ★

スライドマスターは **全スライド共通のデザインの元（ひな形）** です。
「全スライドにロゴを入れたい」「全スライドのタイトルのフォントを変えたい」ときに使います。

表示タブ →「スライドマスター」

```
スライドマスター（一番上の大きいもの）   ← ここを変えると全レイアウトに反映
 ├─ タイトルスライド レイアウト
 ├─ タイトルとコンテンツ レイアウト     ← ここを変えるとこのレイアウトのスライドだけに反映
 ├─ セクション見出し レイアウト
 └─ …
```

| スライドマスターでやること | 例 |
|----------------------------|-----|
| フォントの統一 | タイトル：游ゴシック 28pt 太字 / 本文：メイリオ 18pt |
| ロゴ・会社名 | 全スライドの右下にロゴ |
| ページ番号 | 挿入タブ →「ヘッダーとフッター」→「スライド番号」にチェック |
| 色 | タイトル下に会社カラーの線 |

> 1 枚ずつフォントを変更するのは非効率で、統一感も崩れます。
> **共通のデザインは必ずスライドマスターで設定** しましょう。
> 会社には社内テンプレートが用意されていることが多いので、配属後はまずそれを使います。

### テーマ

デザインタブ →「テーマ」で、配色・フォント・背景をまとめて変更できます。
「バリエーション」で配色やフォントだけを変えることもできます。

## 6. スライドショーの操作 ★

| 操作 | キー |
|------|------|
| 最初から開始 | `F5` |
| 現在のスライドから開始 | `Shift + F5` |
| 発表者ツールで開始 | `Alt + F5` |
| 次へ | `Enter` / `→` / `↓` / `Space` / `N` / クリック |
| 前へ | `Backspace` / `←` / `↑` / `P` |
| 指定したスライドへ | 番号を入力して `Enter`（例：`5` → `Enter`）|
| 最初 / 最後のスライド | `Home` / `End` |
| 画面を黒にする / 戻す | `B` |
| 画面を白にする / 戻す | `W` |
| ペンを使う | `Ctrl + P` |
| レーザーポインター | `Ctrl + L` |
| 矢印に戻す | `Ctrl + A` |
| 終了 | `Esc` |

> **`B` キー（ブラックアウト）** は、スライドから聴衆の注意を外して
> 自分の話に集中してほしいときや、質疑応答のときに便利です。

### 発表者ツール

プロジェクターや外部モニターにつないだとき、
**聴衆にはスライドだけ、自分の画面にはノート・次のスライド・経過時間** を表示する機能です。

```
自分の画面（発表者ツール）
┌──────────────────────┬──────────────┐
│                      │ 次のスライド   │
│   現在のスライド        │ ▭            │
│                      ├──────────────┤
│ ⏱ 0:03:25            │ ノート         │
│ ◀ ▶  🖊  🔍           │ ・ここで A を説明 │
└──────────────────────┴──────────────┘
```

スライドショータブ →「発表者ツールを使用する」にチェック。
外部モニターがなくても `Alt + F5` で発表者ツールの練習ができます。

## 7. 印刷と保存

### 配布資料の印刷

ファイル →「印刷」→「フルページサイズのスライド」の ▼ から選べます。

| 印刷レイアウト | 用途 |
|----------------|------|
| フルページサイズのスライド | 1 ページに 1 スライド |
| ノート | 上にスライド、下にノート（発表原稿として）|
| アウトライン | 文字だけ |
| 配布資料（2 / 3 / 4 / 6 / 9 スライド）| 聴衆への配布用。3 スライドはメモ欄付き |

### 保存形式

| 形式 | 用途 |
|------|------|
| `.pptx` | 通常の保存 |
| `.pdf` | 配布用（レイアウトが崩れない）|
| `.ppsx` | 開くとすぐスライドショーが始まる |
| `.mp4` | 動画として書き出し（ナレーションも含められる）|
| `.png` / `.jpg` | スライドを画像として保存 |

## やってみよう（15 分）

1. アウトライン表示で、3 スライド分のタイトルと箇条書きを入力する
2. 四角形を 1 つ描き、`Ctrl + D` を 3 回押して等間隔に複製されることを確認する
3. 大きさの違う図形を 4 つ適当に置き、「上揃え」→「左右に整列」できれいに並べる
4. スライドマスターで、全スライドの右下に会社名のテキストを入れる
5. `F5` でスライドショーを開始し、`B` キー、`3` → `Enter`、`Ctrl + L` を試す
