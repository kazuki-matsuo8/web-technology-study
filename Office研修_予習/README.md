## この資料について

新入社員研修でよく扱われる Word・Excel・PowerPoint の内容を、
「研修当日に手が止まらない」レベルまで予習するための資料です。

IT 企業では、Office 製品は「事務作業の道具」ではなく **開発業務そのものの道具** として使われます。

| 製品 | 開発現場での主な用途 |
|------|----------------------|
| Word | 議事録、報告書、マニュアル、社外向け文書（送付状・お知らせ）|
| Excel | 設計書、テスト仕様書、課題管理表、WBS（スケジュール表）、データ集計 |
| PowerPoint | 提案資料、進捗報告、研修の成果発表、社内プレゼン |

操作を覚えるだけでなく、**「なぜその機能を使うのか」「読み手にとって何が親切か」** を意識すると、
研修でも配属後でも評価されやすくなります。

> ※ 画面やメニュー名は Microsoft 365（Windows 版）を基準にしています。
> 研修で使うバージョン（2019 / 2021 / 365 など）や Mac 版では一部名称・位置が異なる場合があります。

## おすすめ予習の進め方

時間が限られている場合は ★ の付いた項目を優先してください。

```
1. 共通ショートカット ★（30分）
   → Ctrl+C / V / Z / S など。研修中ずっと使う

2. Excel ★★★（2〜3時間）
   → 研修で一番時間を割かれることが多く、差がつきやすい
   → 「絶対参照」「IF」「VLOOKUP / XLOOKUP」「SUMIF / COUNTIF」は必ず手を動かす

3. Word ★★（1時間）
   → ビジネス文書の型（頭語・結語・記書き）と、インデント・タブの使い方

4. PowerPoint ★★（1時間）
   → 操作よりも「1スライド1メッセージ」などの考え方が重要

5. 確認テスト（30分）
   → 間違えた問題の章だけ読み直す
```

**ポイント：読むだけでなく、必ず実際に Office を開いて手を動かすこと。**
各章の「やってみよう」は 5 分程度で終わる小さな操作練習です。

## 研修当日のチェックリスト

- [ ] Office にサインインできるか（研修用アカウントの ID・パスワード）
- [ ] 日本語入力（IME）の切り替えができるか（半角/全角キー）
- [ ] ファイルの保存先（OneDrive / ローカル / 共有フォルダー）を把握しているか
- [ ] 拡張子が表示される設定か（エクスプローラー →「表示」→「ファイル名拡張子」）
- [ ] こまめに `Ctrl + S` で保存する習慣
- [ ] 分からない操作は「操作アシスト（検索ボックス）」に機能名を入力して探す
