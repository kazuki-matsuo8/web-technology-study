# 00-01：Office 共通操作とショートカット

---

## 1. Office 共通の画面構成

Word・Excel・PowerPoint は画面構成がほぼ共通です。一度覚えれば 3 製品で使い回せます。

```
┌──────────────────────────────────────────────────┐
│ [クイックアクセスツールバー]   ファイル名 - Excel    🔍検索 │ ← タイトルバー
├──────────────────────────────────────────────────┤
│ ファイル ホーム 挿入 描画 ページレイアウト 数式 ...      │ ← タブ
├──────────────────────────────────────────────────┤
│ [貼り付け] [B I U] [フォント] ...                      │ ← リボン
│  クリップボード │  フォント   │ 配置 ...  ← グループ名    │
├──────────────────────────────────────────────────┤
│                                                  │
│                 作業領域                           │
│                                                  │
├──────────────────────────────────────────────────┤
│ ステータスバー                     表示切替  ズーム     │
└──────────────────────────────────────────────────┘
```

| 名称 | 役割 |
|------|------|
| リボン | 機能のボタンがまとまった帯。タブを切り替えると中身が変わる |
| タブ | 「ホーム」「挿入」など機能の分類 |
| グループ | タブ内の機能のまとまり。右下の `↘`（ダイアログボックス起動ツール）で詳細設定画面が開く |
| クイックアクセスツールバー | よく使うボタン（上書き保存・元に戻すなど）を常に表示しておける場所 |
| ステータスバー | Excel では選択範囲の **合計・平均・データの個数** が表示される（地味に便利）|
| Backstage ビュー | 「ファイル」タブで開く画面。保存・印刷・エクスポート（PDF 化）など |

### コンテキストタブ

表や図形、グラフを選択したときだけ現れるタブがあります（例：「テーブルデザイン」「図形の書式」）。
**「目的のメニューが見つからない」ときは、まず対象をクリックして選択してみる** のがコツです。

### 右クリックメニューとミニツールバー

選択した対象を右クリックすると、その場で使える機能だけが表示されます。
リボンから探すより早いことが多いです。

## 2. ファイル操作の基本

### 保存の種類

| 操作 | ショートカット | 説明 |
|------|----------------|------|
| 上書き保存 | `Ctrl + S` | 今のファイルに保存 |
| 名前を付けて保存 | `F12` | 別名・別形式で保存（バージョン違いを残したいとき）|
| PDF として保存 | ファイル → エクスポート | 社外に渡す・印刷用に崩れない形で配布する |

### 主な拡張子

| 拡張子 | 内容 |
|--------|------|
| `.docx` | Word 文書 |
| `.xlsx` | Excel ブック |
| `.xlsm` | マクロ付き Excel ブック |
| `.pptx` | PowerPoint プレゼンテーション |
| `.csv` | カンマ区切りテキスト（Excel で開けるが、書式や数式は保存されない）|
| `.pdf` | 印刷イメージを固定した文書。相手の環境でレイアウトが崩れない |

### ファイル名の付け方（実務での作法）

```
❌ 資料.xlsx / 最新.docx / 最新_修正_本当に最終.pptx
⭕ 20261012_Office研修_議事録_v1.0.docx
⭕ 【社外秘】顧客管理システム_基本設計書_v1.2.xlsx
```

- 日付（`YYYYMMDD`）・内容・バージョンを入れると、ファイル一覧で並べたときに探しやすい
- 「最新」「最終」は使わない（さらに新しい版ができたときに破綻する）

## 3. 全製品共通ショートカット ★

まずはこの表を全部覚えましょう。マウス操作より圧倒的に速くなります。

### 編集の基本

| ショートカット | 操作 |
|----------------|------|
| `Ctrl + C` | コピー |
| `Ctrl + X` | 切り取り |
| `Ctrl + V` | 貼り付け |
| `Ctrl + Z` | 元に戻す |
| `Ctrl + Y` | やり直し（または直前の操作の繰り返し）|
| `Ctrl + A` | すべて選択 |
| `Ctrl + F` | 検索 |
| `Ctrl + H` | 置換 |
| `Ctrl + S` | 上書き保存 |
| `Ctrl + P` | 印刷 |
| `Ctrl + N` | 新規作成 |
| `Ctrl + O` | 開く |
| `Ctrl + W` | ファイルを閉じる |
| `F4` | 直前の操作を繰り返す（Excel の数式入力中は参照の切替）|

### 書式

| ショートカット | 操作 |
|----------------|------|
| `Ctrl + B` | 太字 |
| `Ctrl + I` | 斜体 |
| `Ctrl + U` | 下線 |
| `Ctrl + Shift + C` | 書式のコピー（Word / PowerPoint）|
| `Ctrl + Shift + V` | 書式の貼り付け（Word / PowerPoint）|

### Windows 操作

| ショートカット | 操作 |
|----------------|------|
| `Alt + Tab` | ウィンドウ切り替え |
| `Windows + D` | デスクトップを表示 |
| `Windows + E` | エクスプローラーを開く |
| `Windows + Shift + S` | 画面の一部をスクリーンショット |
| `Windows + V` | クリップボード履歴（設定で有効化が必要）|
| `Windows + ← / →` | ウィンドウを画面の左右半分に配置 |

### 日本語入力（IME）

| キー | 変換結果 |
|------|----------|
| `F6` | ひらがな |
| `F7` | 全角カタカナ |
| `F8` | 半角カタカナ |
| `F9` | 全角英数 |
| `F10` | 半角英数 |

例：「てすと」と入力して `F7` → 「テスト」、`F10` → 「tesuto」

## 4. Alt キーでリボンを操作する

`Alt` キーを押すと、リボンの各ボタンにアルファベットが表示されます。
順番にキーを押すと、マウスを使わずに操作できます。

```
Alt → H → B → A  （Excel：ホーム → 罫線 → 格子）
Alt → N → T      （Excel：挿入 → テーブル）
```

覚える必要はありませんが、「こういう方法もある」と知っておくと便利です。

## 5. 貼り付けのオプション

コピーしたものを別の場所に貼り付けると、書式も一緒に付いてきます。
Web ページやメールから貼り付けたら、**フォントがバラバラになった** というのはよくある失敗です。

| 貼り付け方法 | 結果 |
|--------------|------|
| 元の書式を保持 | コピー元の見た目のまま貼る |
| 書式を結合 | 貼り付け先の書式に合わせる |
| テキストのみ保持 | 文字だけを貼る（**一番安全**）|
| 値の貼り付け（Excel）| 数式ではなく計算結果だけを貼る |

貼り付け直後に表示される `(Ctrl)▼` ボタン、または右クリック →「貼り付けのオプション」から選べます。

> **Tip**：`Ctrl + Shift + V` は Word / PowerPoint では「書式の貼り付け」、
> Teams やブラウザなどでは「書式なし貼り付け」になります。アプリによって意味が違うので注意。

## 6. 困ったときの対処

| 困りごと | 対処 |
|----------|------|
| 機能の場所が分からない | タイトルバーの検索ボックス（操作アシスト）に機能名を入力 |
| 操作を間違えた | 慌てず `Ctrl + Z` |
| ファイルが固まった・落ちた | 再起動後「ドキュメントの回復」から復元。普段から `Ctrl + S` |
| リボンが消えた | `Ctrl + F1` でリボンの表示 / 非表示を切り替え |
| 入力モードがおかしい | `半角/全角` キー、`Caps Lock` / `Insert`（上書きモード）を確認 |

## やってみよう（5 分）

1. Word を開き、「てすと」と入力して `F7` / `F10` で変換してみる
2. 文字を入力して `Ctrl + B` → `Ctrl + Z` → `Ctrl + Y` の順に押してみる
3. `Windows + Shift + S` で画面の一部を切り取り、Word に `Ctrl + V` で貼り付ける
4. `F12` を押して「名前を付けて保存」画面を開き、ファイルの種類に PDF があることを確認する
