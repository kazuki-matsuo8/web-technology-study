# Word-02：文字書式・段落書式・ページ設定

---

## 1. 書式には 3 つのレベルがある

Word の書式は「どこに対して設定するか」で 3 つに分かれます。
**この区別を理解することが Word 上達の一番の近道** です。

| レベル | 対象 | 主な設定 | 設定場所 |
|--------|------|----------|----------|
| 文字書式 | 選択した文字 | フォント・サイズ・太字・色・下線 | ホーム →「フォント」グループ |
| 段落書式 | 段落全体（カーソルがある段落）| 配置・インデント・行間・箇条書き | ホーム →「段落」グループ |
| ページ設定（セクション書式）| ページ・文書全体 | 用紙サイズ・余白・向き・文字数と行数 | レイアウトタブ |

> 段落書式は **段落内にカーソルを置くだけ** で設定できます（文字を選択する必要なし）。

---

## 2. 文字書式

### フォントの基本

| 項目 | ビジネス文書の目安 |
|------|--------------------|
| 本文フォント | 游明朝 / MS 明朝（印刷物）、游ゴシック / メイリオ（画面で読む資料）|
| 本文サイズ | 10.5pt〜11pt（Word の既定は 10.5pt）|
| タイトル | 14〜16pt、太字 |
| 色 | 基本は黒。強調は太字か 1 色だけ |

- **明朝体**：線に強弱があり、長文でも目が疲れにくい → 印刷する文書の本文向き
- **ゴシック体**：線が均一で目立つ → 見出し・画面表示・スライド向き

### よく使う文字書式ショートカット

| ショートカット | 操作 |
|----------------|------|
| `Ctrl + B` / `I` / `U` | 太字 / 斜体 / 下線 |
| `Ctrl + ]` / `Ctrl + [` | フォントサイズを 1pt 大きく / 小さく |
| `Ctrl + Shift + >` / `<` | フォントサイズを段階的に大きく / 小さく |
| `Ctrl + D` | 「フォント」ダイアログを開く |
| `Ctrl + Space` | 文字書式をクリア |
| `Ctrl + Shift + C` / `V` | 書式のコピー / 貼り付け |

### 書式のコピー（ハケのアイコン）

ホームタブの「書式のコピー/貼り付け」（ハケ）ボタン：
- **1 回クリック**：1 回だけ書式を貼り付け
- **ダブルクリック**：何度でも貼り付けられる（`Esc` で解除）

### ルビ・囲い文字・均等割り付け

| 機能 | 用途 | 場所 |
|------|------|------|
| ルビ | 読み仮名（ふりがな）を振る | ホーム →「ルビ」(亜) |
| 均等割り付け | 「氏　名」「住　所」のように文字幅をそろえる | ホーム →「均等割り付け」|
| 囲い文字 | ㊙ のような記号 | ホーム →「囲い文字」|

```
均等割り付けの例（4 文字分の幅にそろえる）

日　　付：2026年10月12日
件　　名：Office 研修について
担当部署：人事部
```

スペースで調整するのではなく、「日付」を選択して **均等割り付け → 4 字** と指定します。

## 3. 段落書式

### 配置

| 配置 | ショートカット | 使う場面 |
|------|----------------|----------|
| 両端揃え | `Ctrl + J` | 本文（既定）|
| 左揃え | `Ctrl + L` | 英文、箇条書き |
| 中央揃え | `Ctrl + E` | タイトル、「記」|
| 右揃え | `Ctrl + R` | 日付、発信者名、「以上」|

> 両端揃えと左揃えの違い：両端揃えは行の右端もそろうように文字間隔を調整します。
> 日本語の本文は両端揃えが基本です。

### インデント ★

インデントは「段落の左右の余白を、ページの余白より内側にずらす」機能です。

```
ルーラー上のマーカー
   ▽ ← 1 行目のインデント（段落の 1 行目だけ）
   △ ← ぶら下げインデント（2 行目以降）
   □ ← 左インデント（段落全体）
                                         △ ← 右インデント
```

| 種類 | 効果 | 使う場面 |
|------|------|----------|
| 字下げ（1 行目のインデント）| 段落の 1 行目だけ下げる | 本文の書き出しを 1 字下げる |
| ぶら下げインデント | 2 行目以降だけ下げる | 「1．」「※」などの後ろで折り返しをそろえる |
| 左インデント | 段落全体を右にずらす | 引用、記書きの中身 |

```
ぶら下げインデントなし：
※ この資料は内定者研修用に作成したものであり、社外への持ち出し
は禁止します。

ぶら下げインデントあり：
※ この資料は内定者研修用に作成したものであり、社外への持ち出し
   は禁止します。
```

ホームタブの「インデントを増やす / 減らす」ボタンでは 1 字ずつ調整できます。
細かく設定するときは「段落」ダイアログ（ホーム →「段落」グループ右下 `↘`）を使います。

### 行間と段落間隔

| 設定 | 意味 |
|------|------|
| 行間 | 段落内の行と行の間隔（1 行 / 1.5 行 / 固定値など）|
| 段落前 / 段落後 | 段落と段落の間のスペース |

> 段落の間を空けたいときに **空の段落（Enter）を入れるのではなく**、
> 「段落後 0.5 行」などで設定すると、文書全体で間隔が統一されます。

### 箇条書きと段落番号

| 機能 | 例 |
|------|-----|
| 箇条書き | ・ ● ■ ✓ |
| 段落番号 | 1. 2. 3. / (1) (2) (3) / ① ② ③ |
| アウトライン（多段階リスト）| 1. → 1.1 → 1.1.1 |

- `Tab` でレベルを下げる、`Shift + Tab` でレベルを上げる
- 段落番号は自動で振り直されるので、手入力しないこと

### タブとリーダー ★

タブは「文字を決まった位置にそろえる」機能です。
目次や、料金表のように「左に項目・右に値」と並べたいときに使います。

```
タブ＋リーダー（点線）を使った例：

第1章　はじめに ……………………………………… 1
第2章　システム概要 ………………………………… 3
第3章　機能一覧 ……………………………………… 8
```

1. 段落を選択し、ルーラー上の目的の位置をクリックして **タブ位置** を設定
2. 「段落」ダイアログ →「タブ設定」で **配置（左・右・中央・小数点）** と **リーダー（……）** を選ぶ
3. 項目と数字の間で `Tab` キーを押す

## 4. ページ設定

レイアウトタブ →「ページ設定」グループ右下の `↘` で詳細設定ができます。

| 項目 | ビジネス文書の一般的な設定 |
|------|---------------------------|
| 用紙サイズ | A4 |
| 印刷の向き | 縦 |
| 余白 | 上下左右 25〜30mm 程度（既定は上 35mm、下左右 30mm）|
| 文字数と行数 | 「文字数と行数を指定する」で 1 行 40 字前後 × 30〜36 行など |
| 段組み | 2 段組みなど（社内報・チラシ）|

> **ページ設定は最初に決める** のが鉄則です。後から余白や用紙サイズを変えると、
> 改行位置や図の位置がすべてずれてしまいます。

### セクション区切り

「1 つの文書の中で、途中から横向きのページにしたい」「表紙だけページ番号を付けたくない」
というときは **セクション区切り** を入れます。

レイアウトタブ →「区切り」→「セクション区切り」→「次のページから開始」

セクションごとに、用紙の向き・余白・ヘッダー/フッター・ページ番号を変えられます。

## 5. スタイル ★

スタイルは「書式のセット」に名前を付けたものです。

```
「見出し 1」スタイル ＝ 游ゴシック ＋ 16pt ＋ 太字 ＋ 段落前 1 行
```

### スタイルを使うメリット

1. **一括変更**：「見出し 1」の書式を変えると、文書中のすべての見出し 1 が変わる
2. **目次の自動作成**：見出しスタイルを付けた文字から目次を自動生成できる
3. **ナビゲーションウィンドウ**：見出しの一覧から目的の章へジャンプできる
4. **統一感**：手作業で書式を付けるより、見た目のばらつきがなくなる

### 使い方

- ホームタブ →「スタイル」ギャラリーから「見出し 1」「見出し 2」などをクリック
- スタイルの書式を変えたいとき：書式を整えた文字を選択 → スタイルを右クリック →「選択個所と一致するように〇〇を更新する」

> 長い文書（マニュアル・報告書・設計書）を Word で書くときは、
> **「見出しは必ず見出しスタイルで」** を徹底しましょう。
