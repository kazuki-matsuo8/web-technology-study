# Word-01：Word の基本操作と画面構成

---

## 1. Word とは

Word は **文書作成ソフト** です。報告書・議事録・送付状・マニュアルなど、
「文章が主役の資料」を作るときに使います。

| こんなときは | 使うソフト |
|--------------|-----------|
| 文章が中心、A4 で印刷・配布する | **Word** |
| 数値の計算・一覧表・データ管理 | Excel |
| 人前で説明する、図解中心 | PowerPoint |

> 「Excel 方眼紙」（Excel のセルを方眼紙のように使って文書を作ること）は
> 日本の職場でよく見かけますが、文章中心の文書は本来 Word が得意です。
> ただし配属先のルールが Excel なら、それに従いましょう。

## 2. 画面構成

```
┌─────────────────────────────────────────────┐
│ ファイル ホーム 挿入 デザイン レイアウト 参考資料 差し込み文書 校閲 表示 │
├─────────────────────────────────────────────┤
│ リボン                                        │
├─────────────────────────────────────────────┤
│  └─ ルーラー（表示タブ →「ルーラー」で表示）        │
│ ┌─────────────────────────────┐            │
│ │  文書（ページ）                 │            │
│ │  | ← カーソル                   │            │
│ └─────────────────────────────┘            │
├─────────────────────────────────────────────┤
│ 1/3 ページ  1,200 文字   日本語        表示モード ズーム │
└─────────────────────────────────────────────┘
```

### 主要タブの役割

| タブ | 主な機能 |
|------|----------|
| ホーム | フォント・段落・スタイル・検索/置換 |
| 挿入 | 表・画像・図形・ヘッダー/フッター・ページ番号・改ページ |
| デザイン | テーマ・透かし・ページの色 |
| レイアウト | 余白・用紙サイズ・印刷の向き・段組み・区切り・インデント |
| 参考資料 | 目次・脚注・図表番号 |
| 差し込み文書 | 差し込み印刷・宛名ラベル |
| 校閲 | スペルチェック・コメント・変更履歴・文字カウント |
| 表示 | 表示モード・ルーラー・ナビゲーションウィンドウ |

### 最初にやっておくと良い設定

1. **ルーラーを表示**：表示タブ →「ルーラー」にチェック（インデントの調整に必須）
2. **編集記号を表示**：ホームタブ →「編集記号の表示/非表示」（`¶` のボタン）

編集記号を表示すると、目に見えない「改行」「スペース」「タブ」が見えるようになります。
**レイアウトが崩れたときの原因調査に必須** です。

| 記号 | 意味 |
|------|------|
| `↵`（段落記号） | `Enter` による段落の区切り |
| `↓` | `Shift + Enter` による段落内改行 |
| `□` / `・` | 全角 / 半角スペース |
| `→` | タブ |

## 3. 文字の選択

効率よく選択できると、編集スピードが一気に上がります。

| 操作 | 選択される範囲 |
|------|----------------|
| ダブルクリック | 単語 |
| トリプルクリック | 段落 |
| 左余白でクリック | 1 行 |
| 左余白でダブルクリック | 段落 |
| 左余白でトリプルクリック / `Ctrl + A` | 文書全体 |
| `Shift + 矢印` | 1 文字ずつ範囲を広げる |
| `Shift + Home / End` | カーソル位置から行頭 / 行末まで |
| `Ctrl + Shift + 矢印` | 単語単位で範囲を広げる |
| `Alt + ドラッグ` | 矩形（四角形）で選択 |
| `Ctrl + ドラッグ` | 離れた場所を複数選択 |

## 4. カーソル移動

| ショートカット | 移動先 |
|----------------|--------|
| `Home` / `End` | 行頭 / 行末 |
| `Ctrl + Home` / `Ctrl + End` | 文書の先頭 / 末尾 |
| `Ctrl + ← / →` | 単語単位で移動 |
| `Ctrl + ↑ / ↓` | 段落単位で移動 |
| `Page Up` / `Page Down` | 1 画面分移動 |
| `Shift + F5` | 直前に編集していた位置へ戻る |

## 5. 改行と改ページ ★

Word で一番やりがちな失敗が「**改行を連打してページを送る**」ことです。

```
❌ 悪い例：次のページから第2章を始めたいので Enter を 20 回押す
   → 前のページの文章を1行足しただけで、全部ずれる

⭕ 良い例：Ctrl + Enter で「改ページ」を入れる
   → 前のページの内容が増減しても、第2章は必ず新しいページから始まる
```

| 操作 | キー | 意味 |
|------|------|------|
| 段落を変える | `Enter` | 新しい段落を始める |
| 段落内で改行 | `Shift + Enter` | 段落を変えずに行だけ変える（箇条書きの中で使う）|
| 改ページ | `Ctrl + Enter` | 強制的に次のページへ |

同様に「**スペースを連打して文字の位置をそろえる**」のも NG です。
位置合わせには **インデント・タブ・配置（中央揃え・右揃え）** を使います（次章で解説）。

## 6. 検索と置換

| 操作 | ショートカット |
|------|----------------|
| 検索（ナビゲーションウィンドウ）| `Ctrl + F` |
| 置換 | `Ctrl + H` |

置換は「文書内の表記ゆれを一括で直す」ときに大活躍します。

```
例：「サーバ」と「サーバー」が混在している
  → 検索する文字列「サーバ」/ 置換後の文字列「サーバー」で全置換
  → ただし「サーバー」が「サーバーー」にならないよう、
    先に「サーバー」→「サーバ」に統一してから「サーバ」→「サーバー」に置換する
```

「オプション」を開くと、ワイルドカード検索や、大文字と小文字の区別などが設定できます。

## 7. 表示モード

| モード | 用途 |
|--------|------|
| 印刷レイアウト | 通常の編集（印刷イメージどおりに表示）|
| 閲覧モード | 読むだけのとき |
| Web レイアウト | Web ページとしての見え方 |
| アウトライン | 見出しの階層構造を整理しながら書く |
| 下書き | 文字だけを高速に編集 |

普段は **印刷レイアウト** を使います。

### ナビゲーションウィンドウ

表示タブ →「ナビゲーションウィンドウ」にチェックすると、
左側に **見出しの一覧** が表示され、クリックでその位置にジャンプできます。
見出しをドラッグして **章の順番を入れ替える** こともできます。
（見出しスタイルを設定していることが前提。Word-04 で解説）

4. `Ctrl + H` で「です」を「である」に一括置換してみる
