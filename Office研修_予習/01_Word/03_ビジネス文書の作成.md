# Word-03：ビジネス文書の作成

---

## 1. ビジネス文書の基本原則

ビジネス文書は「読み手が短時間で正確に内容を理解できる」ことが最優先です。

| 原則 | 内容 |
|------|------|
| 1 文書 1 用件 | 複数の用件を 1 つの文書に混ぜない |
| 結論を先に | 「何の文書か」「何をしてほしいか」を最初に書く |
| 簡潔に | 1 文は 50〜60 字程度まで。長い文は分ける |
| 5W2H を明確に | いつ・どこで・誰が・何を・なぜ・どのように・いくら |
| 箇条書きを活用 | 日時・場所・持ち物などは「記」以下に箇条書き |
| 正確に | 日付・曜日・数字・固有名詞は必ず見直す |

### 5W2H

| 項目 | 意味 | 例 |
|------|------|-----|
| When | いつ | 2026 年 10 月 20 日（火）13:00〜17:00 |
| Where | どこで | 本社 5 階 第 1 会議室 |
| Who | 誰が | 2027 年度入社内定者 |
| What | 何を | Office 研修（Excel 編）|
| Why | なぜ | 配属後の資料作成業務に備えるため |
| How | どのように | ノート PC を使用したハンズオン形式 |
| How much | いくら | 参加費なし |

## 2. 社内文書と社外文書

| | 社内文書 | 社外文書 |
|-|----------|----------|
| 例 | 通知・報告書・議事録・稟議書・企画書 | 案内状・依頼状・送付状・お礼状・お詫び状 |
| 挨拶 | 不要（簡潔さ優先）| 必要（頭語・時候の挨拶・結語）|
| 敬語 | 丁寧語（です・ます）が中心 | 尊敬語・謙譲語を正しく使う |
| 重視すること | 効率・正確さ | 礼儀・会社の信用 |

## 3. 社内文書の構成

```
                                              総発第 123 号  ← ①文書番号
                                          2026年10月12日  ← ②発信日付
内定者各位                                                 ← ③受信者名
                                              人事部 研修課  ← ④発信者名
                                              担当：山田

              Office 研修の実施について（通知）              ← ⑤件名

 標記の件について、下記のとおり実施しますので、               ← ⑥本文
ご参加ください。

                          記                              ← ⑦記書き

1．日　　時　2026年10月20日（火）13:00～17:00
2．場　　所　本社 5 階　第 1 会議室
3．内　　容　Word・Excel・PowerPoint の基本操作
4．持 ち 物　貸与ノート PC、筆記用具

                                                    以上  ← ⑧結び
```

| 要素 | ポイント | Word での設定 |
|------|----------|---------------|
| ① 文書番号 | 社内規程で決まっている場合のみ | 右揃え |
| ② 発信日付 | 元号か西暦かは社内ルールに従う | 右揃え |
| ③ 受信者名 | 複数人宛は「各位」（「各位殿」「各位様」は誤り）| 左揃え |
| ④ 発信者名 | 部署名・担当者名・連絡先 | 右揃え |
| ⑤ 件名 | 内容がひと目で分かるように。末尾に（通知）（依頼）など | 中央揃え・少し大きく・太字 |
| ⑥ 本文 | 用件を簡潔に | 両端揃え |
| ⑦ 記 | 詳細を箇条書きで | 「記」は中央揃え。項目は均等割り付け |
| ⑧ 以上 | 文書の終わりを示す | 右揃え |

> **Word の自動入力機能**：「記」と入力して `Enter` を押すと、
> 自動で「記」が中央揃えになり、下に右揃えの「以上」が入力されます。
> 同様に「拝啓」と入力して `Enter` を押すと「敬具」が自動で右揃えで入ります。

## 4. 社外文書の構成

```
                                          2026年10月12日
株式会社〇〇
営業部　部長　佐藤 一郎 様
                                          株式会社△△
                                          営業部　田中 花子

                  資料送付のご案内

拝啓　秋冷の候、貴社ますますご清栄のこととお慶び申し上げます。  ← 前文
平素は格別のお引き立てを賜り、厚く御礼申し上げます。

　さて、先日ご依頼いただきました製品資料を、下記のとおり送付  ← 主文
いたしますので、ご査収くださいますようお願い申し上げます。

　まずは略儀ながら書中にてご案内申し上げます。                ← 末文
                                                    敬具  ← 結語
                          記

1．製品カタログ　　　　　　　1部
2．価格表　　　　　　　　　　1部

                                                    以上
```

### 前文の 4 要素

```
拝啓　　　　秋冷の候、　　　貴社ますますご清栄のこととお慶び申し上げます。　平素は格別のお引き立てを賜り…
└頭語┘　　└時候の挨拶┘　　└──────── 慶賀の挨拶 ────────┘　　└──── 感謝の挨拶 ────┘
```

### 頭語と結語の組み合わせ ★

頭語と結語は **必ずセット** で使います。

| 場面 | 頭語 | 結語 |
|------|------|------|
| 一般的な文書 | 拝啓 | 敬具 |
| 特に丁寧な文書 | 謹啓 | 謹白 / 敬白 |
| 前文を省略する | 前略 | 草々 |
| 返信 | 拝復 | 敬具 |
| 急ぎ | 急啓 | 草々 |

> 「前略」は「前文（時候の挨拶など）を省略します」という意味です。
> 目上の人や取引先には使わないのが無難です。

### 時候の挨拶（月別の例）

| 月 | 例 | 月 | 例 |
|----|-----|----|-----|
| 1 月 | 新春の候 / 厳寒の候 | 7 月 | 盛夏の候 / 猛暑の候 |
| 2 月 | 余寒の候 / 立春の候 | 8 月 | 残暑の候 / 晩夏の候 |
| 3 月 | 早春の候 / 春暖の候 | 9 月 | 初秋の候 / 新秋の候 |
| 4 月 | 陽春の候 / 春暖の候 | 10 月 | 秋冷の候 / 紅葉の候 |
| 5 月 | 新緑の候 / 薫風の候 | 11 月 | 晩秋の候 / 向寒の候 |
| 6 月 | 梅雨の候 / 初夏の候 | 12 月 | 師走の候 / 初冬の候 |

迷ったら、季節を問わず使える「**時下**」（時下ますますご清栄のこととお慶び申し上げます）も使えます。

> **Word の「あいさつ文」機能**：挿入タブ →「あいさつ文」→「あいさつ文の挿入」で、
> 月を選ぶだけで時候の挨拶・安否の挨拶・感謝の挨拶を組み合わせて挿入できます。

### 慶賀の挨拶の使い分け

| 相手 | 表現 |
|------|------|
| 会社・団体 | 貴社ますます**ご清栄**（ご隆盛・ご発展）のこととお慶び申し上げます |
| 個人 | 〇〇様にはますます**ご健勝**のこととお慶び申し上げます |

### 末文の例

- まずは略儀ながら書中にてご案内申し上げます。
- 今後とも変わらぬお引き立てのほど、よろしくお願い申し上げます。
- 取り急ぎ、ご連絡まで。（社内・親しい相手向け）

## 5. 敬称の使い分け ★

| 敬称 | 使う相手 | 例 |
|------|----------|-----|
| 様 | 個人 | 佐藤 一郎 様 |
| 御中 | 会社・部署（個人名がない）| 株式会社〇〇 人事部 御中 |
| 各位 | 複数の人 | 関係者各位、お客様各位 |
| 殿 | 社内の公式文書（目下宛）。現在は「様」に統一する会社が多い | |

**よくある間違い**

```
❌ 株式会社〇〇 人事部 御中 佐藤様   （御中と様の併用）
⭕ 株式会社〇〇 人事部 佐藤 一郎 様

❌ 佐藤部長様                          （役職自体が敬称なので二重敬語）
⭕ 部長 佐藤 一郎 様 / 佐藤部長

❌ 関係者各位様
⭕ 関係者各位
```

### 自分側と相手側の呼び方

| | 相手側（尊敬）| 自分側（謙譲）|
|-|---------------|---------------|
| 会社 | 貴社（書き言葉）/ 御社（話し言葉）| 当社 / 弊社 |
| 人 | 〇〇様 | 私 / 担当者 |
| 物 | ご高著・ご配慮 | 粗品・拙著 |
| 受け取る | ご査収ください | 拝受しました |

## 6. 議事録の書き方

研修や配属後に必ず書くことになるのが **議事録** です。

```
                       議事録

日　　時：2026年10月12日（月）10:00～11:00
場　　所：本社 3 階 会議室 B（Teams 併用）
出 席 者：〈社〉山田、鈴木、松尾　〈客〉佐藤様、高橋様
記 録 者：松尾

1．目的
   〇〇システム改修の要件確認

2．決定事項
   ・ログイン画面に「パスワードを忘れた方」リンクを追加する
   ・リリース日は 2026 年 12 月 1 日とする

3．課題・宿題（ToDo）
   No.  内容                        担当     期限
   1    画面イメージの作成           鈴木     10/16
   2    既存ユーザー数の確認         佐藤様   10/19

4．次回予定
   2026年10月19日（月）10:00～　同会議室
                                                    以上
```

### 議事録のポイント

- **決定事項と ToDo（誰が・何を・いつまでに）を明確に** するのが最重要
- 発言をすべて書き起こすのではなく、**結論と根拠** を要約する
- 会議当日中（遅くとも翌日）に共有する
- 社外の方の名前には「様」を付ける

## 7. 提出前のチェックリスト

- [ ] 日付・曜日は正しいか（カレンダーで確認）
- [ ] 宛名・敬称は正しいか（御中と様の併用をしていないか）
- [ ] 頭語と結語の組み合わせは合っているか
- [ ] 誤字脱字はないか（校閲タブ →「スペルチェックと文章校正」）
- [ ] 表記ゆれはないか（「サーバ / サーバー」「行う / 行なう」）
- [ ] 数字の全角 / 半角が統一されているか
- [ ] 印刷プレビューで 1 ページに収まっているか、最終ページに 1〜2 行だけはみ出していないか
