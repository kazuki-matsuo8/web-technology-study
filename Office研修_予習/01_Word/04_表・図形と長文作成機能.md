# Word-04：表・図形・画像・長文作成機能

---

## 1. 表の作成

### 表を挿入する

挿入タブ →「表」→ マス目をドラッグして行数・列数を指定します。

```
┌──────┬──────────┬──────┐
│ No.  │ 項目      │ 担当  │  ← 見出し行（太字・背景色）
├──────┼──────────┼──────┤
│ 1    │ 画面設計  │ 鈴木  │
│ 2    │ DB 設計   │ 松尾  │
└──────┴──────────┴──────┘
```

### 表の操作

| やりたいこと | 操作 |
|--------------|------|
| 次のセルへ移動 | `Tab`（最後のセルで `Tab` を押すと行が追加される）|
| 前のセルへ移動 | `Shift + Tab` |
| 行・列の挿入 | 表の左端 / 上端に表示される `⊕` をクリック、または右クリック →「挿入」|
| 行・列の削除 | 選択して `Backspace`（`Delete` だと中身だけ消える）|
| セルの結合 / 分割 | 選択して右クリック →「セルの結合」/「セルの分割」|
| 列幅を自動調整 | 「レイアウト」タブ →「自動調整」→「文字列の幅に自動調整」|
| 列幅をそろえる | 「レイアウト」タブ →「幅を揃える」|
| デザインを変える | 「テーブルデザイン」タブ →「表のスタイル」|
| 見出し行を次ページにも表示 | 見出し行を選択 →「レイアウト」タブ →「タイトル行の繰り返し」|

> 表を選択すると「テーブルデザイン」「レイアウト」の **コンテキストタブ** が表示されます。

### Excel の表を貼り付ける

| 貼り付け方 | 結果 |
|------------|------|
| 通常の貼り付け | Word の表になる（Word で編集可能）|
| 図として貼り付け | 画像になる（編集不可・レイアウトが崩れない）|
| リンク貼り付け | 元の Excel を更新すると Word にも反映される |

## 2. 画像・図形

### 文字列の折り返し ★

画像を挿入したら、まず **文字列の折り返し** を設定します。
これを知らないと「画像が思った位置に動かない」で必ず苦労します。

画像を選択 → 右上に出る「レイアウトオプション」アイコン、または「図の形式」タブ →「文字列の折り返し」

| 設定 | 動き | 使う場面 |
|------|------|----------|
| 行内（既定）| 画像を 1 つの大きな文字として扱う | 画像を段落の中に置くだけのとき（**一番崩れにくい**）|
| 四角形 | 画像の周りを文字が四角く回り込む | 本文の横に写真を置く |
| 上下 | 画像の上下に文字が来る（左右には来ない）| 図を独立して置く |
| 背面 / 前面 | 文字と重ねる | ロゴ・透かし・図形での注釈 |

> 迷ったら「**行内**」にして、段落の配置（中央揃えなど）で位置を調整するのが安全です。

### 図形

挿入タブ →「図形」から、矢印・四角形・吹き出しなどを挿入できます。

| 操作 | 方法 |
|------|------|
| 正方形・正円を描く | `Shift` を押しながらドラッグ |
| 水平・垂直に移動 | `Shift` を押しながらドラッグ |
| コピー | `Ctrl` を押しながらドラッグ |
| 複数の図形をまとめる | `Shift` で複数選択 → 右クリック →「グループ化」|
| 図形に文字を入れる | 図形を選択してそのまま入力 |

### SmartArt

挿入タブ →「SmartArt」で、手順・階層・循環などの図解を簡単に作れます。
（PowerPoint でも同じ機能が使えます。詳細は PowerPoint-03 で解説）

## 3. ヘッダー・フッター・ページ番号

| 機能 | 場所 | 用途 |
|------|------|------|
| ヘッダー | ページ上部の余白 | 文書名、社外秘表示、作成日 |
| フッター | ページ下部の余白 | ページ番号、会社名 |
| ページ番号 | 挿入タブ →「ページ番号」| 「1 / 10」形式（X / Y ページ）など |

- ページ上部・下部の余白をダブルクリックすると編集できます
- 本文に戻るには、本文部分をダブルクリック、または「ヘッダーとフッターを閉じる」
- 「先頭ページのみ別指定」にチェックすると、**表紙だけページ番号を消す** ことができます

## 4. 目次の自動作成 ★

見出しスタイル（Word-02 参照）を設定していれば、目次は自動で作れます。

1. 目次を入れたい位置（表紙の次のページなど）にカーソルを置く
2. 参考資料タブ →「目次」→「自動作成の目次」を選ぶ
3. 本文を修正してページ番号が変わったら、目次をクリック →「目次の更新」

```
目次
1. はじめに ................................ 1
2. システム概要 ............................ 2
   2.1 目的 ................................ 2
   2.2 対象範囲 ............................ 3
3. 機能一覧 ................................ 4
```

> 目次を手入力すると、ページ番号がずれたときに全部手直しが必要になります。
> 「見出しスタイル → 目次自動作成」の流れは、長文作成の基本です。

### 図表番号と相互参照

- 参考資料タブ →「図表番号の挿入」で「図 1」「表 1」のような番号を自動で振れます
- 「相互参照」を使うと、本文中で「図 3 を参照」と書いた番号も自動更新されます

## 5. 共同作業の機能（校閲タブ）

チームで文書をレビューするときに使います。開発現場では設計書や報告書のレビューで頻繁に使います。

### コメント

- 文字を選択 → 校閲タブ →「新しいコメント」
- 「〇〇の根拠を追記してください」のように、本文を直接書き換えずに指摘できる
- 対応したら「解決」にする

### 変更履歴 ★

校閲タブ →「変更履歴の記録」をオンにすると、
誰が・どこを・どう変えたかが記録されます。

```
Office 研修は ~~10月19日~~ 10月20日 に実施します。
                ↑削除（取り消し線）  ↑追加（下線・色付き）
```

| 操作 | 意味 |
|------|------|
| 承諾 | 変更を確定する |
| 元に戻す（反映しない）| 変更を取り消す |
| 「シンプルな変更履歴 / すべての変更履歴 / 変更履歴なし」| 表示の切り替え（記録自体は残る）|

> **注意**：社外に送る前には、変更履歴とコメントがすべて解決されているか必ず確認しましょう。
> 「変更履歴なし」表示にしていても、**履歴自体はファイルに残っています**。
> ファイル →「情報」→「問題のチェック」→「ドキュメント検査」で確認できます。

### 比較

校閲タブ →「比較」で、2 つのファイルの違いを変更履歴の形式で表示できます。
「どこが変わったか分からない」ときに便利です。

## 6. 差し込み印刷

同じ文面の文書を、宛名だけ変えて大量に作る機能です。

```
Excel の宛名リスト                     Word の文書（ひな形）
┌─────────┬─────────┐                ┌────────────────────┐
│ 会社名   │ 氏名     │                │ «会社名»            │
├─────────┼─────────┤      ＋        │ «氏名» 様           │
│ A 社     │ 佐藤     │                │                    │
│ B 社     │ 鈴木     │                │ 拝啓 …              │
└─────────┴─────────┘                └────────────────────┘
                         ↓
         A 社 佐藤様宛、B 社 鈴木様宛 … の文書が自動で作られる
```

差し込み文書タブ →「差し込み印刷の開始」→「宛先の選択」→「差し込みフィールドの挿入」→「完了と差し込み」

## 7. PDF にして配布する

ファイル →「エクスポート」→「PDF/XPS の作成」、または `F12` →「ファイルの種類」で PDF を選択。

- 相手の環境（フォントの有無・Word のバージョン）に関係なく同じ見た目になる
- 社外に送る資料は、編集されたくない場合 PDF で送るのが一般的
- 見出しスタイルを使っていれば、PDF にも「しおり（ブックマーク）」が付けられる
