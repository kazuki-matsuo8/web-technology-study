# Web を支える技術 — 学習ガイド

> 山本陽平 著「Web を支える技術 —— HTTP、URI、HTML、そして REST」をベースにした学習ノート

---

## この資料について

Web の根幹を支える技術（URI・HTTP・HTML・REST）を体系的に理解するための学習資料です。
ただ暗記するのではなく「なぜそう設計されているのか」という思想・背景まで理解することを目指しています。

## 推奨学習順序

```
Week 1:  第1章 Web の基礎（Web の思想・背景を掴む）
Week 2:  第2章 URI（リソースの識別を理解する）
Week 3:  第3章 HTTP（通信の仕組みを完全に理解する）
Week 4:  第4章 ハイパーメディア（データ表現を学ぶ）
Week 5:  第5章 REST（アーキテクチャ設計の思想を身につける）
Week 6:  第6章 発展トピック + 復習
```
