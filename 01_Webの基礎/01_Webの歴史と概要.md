# 第1章-01：Web の歴史と概要

---

## 1. Web とは何か

World Wide Web（WWW、単に "Web"）は、インターネット上に構築された **情報共有システム** のことです。
電子メールや FTP といった他のインターネットサービスと混同しがちですが、Web は独自の仕組みを持っています。

Web の本質は「**ハイパーテキストで相互にリンクされた文書の集合**」です。
単にファイルを転送するだけでなく、文書同士がリンクで結びついている点が革新的でした。

---

## 2. Web の誕生（1989〜1991年）

### ティム・バーナーズ＝リーの提案

1989年、CERN（欧州原子核研究機構）の研究者 **ティム・バーナーズ＝リー（Tim Berners-Lee）** が
「Information Management: A Proposal」という文書を提出しました。

当時の CERN では、多くの研究者が世界中に散在しており、情報共有が困難でした。
バーナーズ＝リーはこの問題を解決するために、ハイパーテキストとインターネットを組み合わせた
システムを提案しました。

1991年、世界初の Web サーバーと Web ブラウザが稼働を開始しました。

### 最初の Web の構成要素

バーナーズ＝リーが考案した3つの要素が、今も Web の中核を成しています。

| 要素 | 役割 |
|------|------|
| HTML | 文書を記述するための言語 |
| HTTP | 文書を転送するためのプロトコル |
| URL（URI） | 文書の場所を示すための識別子 |

この3つは現在も変わらず Web を支えています。

---

## 3. Web の爆発的普及（1993〜）

### Mosaic の登場

1993年、NCSA（米国立スーパーコンピューター応用研究所）が **Mosaic** という Web ブラウザを公開しました。
画像をインラインで表示できる GUI ブラウザで、一般ユーザーにも扱いやすかったため爆発的に普及しました。

Mosaic の開発者の一人であるマーク・アンドリーセンは、のちに **Netscape Navigator** を開発します。

### Web の商業化

1994年ごろから Web が商業利用され始め、企業の Web サイトが増加しました。
同年、バーナーズ＝リーは **W3C（World Wide Web Consortium）** を設立し、
Web の標準化活動を開始しました。

---

## 4. Web の発展の歴史

| 年 | 出来事 |
|----|--------|
| 1989 | バーナーズ＝リーが Web を提案 |
| 1991 | 世界初の Web サーバー・ブラウザ稼働 |
| 1993 | Mosaic 公開、Web が一般普及 |
| 1994 | W3C 設立、Netscape Navigator 公開 |
| 1995 | HTTP/1.0 策定、JavaScript 誕生 |
| 1996 | CSS 1.0 勧告 |
| 1997 | HTTP/1.1 策定（RFC 2068）|
| 1998 | Google 設立、XML 勧告 |
| 1999 | RFC 2616 HTTP/1.1 改訂、REST 概念提唱 |
| 2000 | Roy Fielding が REST を論文で定義 |
| 2004 | Ajax の台頭、Web 2.0 ブーム |
| 2005 | JSON が普及し始める |
| 2012 | HTTP/2 の草案策定開始 |
| 2015 | HTTP/2 策定（RFC 7540）|
| 2022 | HTTP/3 策定（RFC 9114）|

---

## 5. Web とインターネットの違い

よく混同されますが、Web とインターネットは別物です。

```
インターネット ── 世界中のコンピューターを繋ぐ「ネットワークのネットワーク」
                    （TCP/IP プロトコル群を使った物理的・論理的な基盤）

Web          ── インターネット上に構築された「情報共有システムのひとつ」
                    （HTTP を使って URI で識別されたリソースをやり取りする）
```

インターネット上には Web 以外にも、電子メール（SMTP/IMAP）、FTP、DNS、SSH など
多くのサービスが存在します。

---

## 6. Web の設計思想

バーナーズ＝リーが Web を設計する際に大切にした思想があります。

### 分散性
特定のサーバーに依存しない。世界中のサーバーが対等につながる。

### 相互運用性
異なるコンピューター・OS・ブラウザ間でも同じ文書を閲覧できる。

### 拡張性
新しい機能を追加しやすい柔軟な設計にする。

### オープン性
仕様を公開し、誰でも実装できるようにする。

この思想が現在まで Web を発展させ続けている原動力です。
閉じたシステムではなく「誰でも参加できる開かれたシステム」であることが Web の本質です。

---

## まとめ

- Web は1989年にティム・バーナーズ＝リーが考案した情報共有システム
- URI・HTTP・HTML の3要素が Web の基礎を成している
- Mosaic の登場で一般普及し、現在も進化を続けている
- Web とインターネットは別物（Web はインターネット上のサービスのひとつ）
- 分散・相互運用・拡張・オープンという設計思想が Web を支えている
